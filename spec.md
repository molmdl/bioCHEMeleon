# Aim

Develop (1) a pymol plugin (2) a VMD tcl script, of a "hide-and-seek" game with molecules. Given a user-provided molecule or pymol scene, the game randomly create representation of choice over it, that the user should identify where is the newly generated items.

## Requirements of the pymol plugin

0. the user install the plugin as a standard PyMOL plugin
1. starting the pymol plugin from manual, a setup window will popup
2. the popup window allow the user to change the following parameters:
   * dropdown to chose which object to start the game, get from PDB, or use demo set (see note 1). If choosing the demo set, opens sub-manual in the dropdown for the items in Note 1.
   * number of hiders to generate (cap a resonable number)
   * checkbox of whether to lock the current scene/representations. 
     * if true, generate hiders from the current representations. then the next item "list of representation of hiders" would create the list detecting current representation(s).
     * if false, randomize representation or use certain presents to start with. the next item "list of representation of hiders" would list all the available representations.
   * list of representation of hiders (optional. if not set, random)
     * checkbox to tick for whether. after checking, feed to a list/form with textbox or scrollwheel to set the number (see below) 
     * textbox to specify the number of each representation to generate (optional)
        * if not set, random of each representation for a total of number of hiders
   * Option to show total remaining hiders in gameplay only (harder) or also show remaining hiders of each representation (easier)
3. the bottom of the popup within would have 7 buttons: (1) Reset, (2) Randomize, (3) Save Setup, (4) Load Setup, (5) Generate and export, (6) Cleanup model (7) Start 
   3.1. Reset: restore the default settings
   3.2. Randomize: randomize setup
   3.3. Save Setup: save the game setup parameters to a file
   3.4. Load Setup: load the setup parameters from a file
   3.5. Generate and export: Only generate the representation of the game and save this initial state to a file for sharing or later loading of the specific game
   3.6. Cleanup model: clean up all the representation generated by the game that is not in the original object 
   3.7. Start: Start the game  
4. Once the user are happy with the game setup, they click "Start"
5. Clicking start do the following:
   * store thet initial state of the object
   * generate the additional representation based on the setup parameters
   * jump to the Game status tab of the same window
   * countdown 3, 2, 1, then start the game
6. the Game status tab shoud have the following:
   * a generic rolling info box
   * timing after the game started (out of info)
   * number of remaining hiders (total number/if selected in setup also remaining hiders of eache representation)
   * import button to import a game prepared by 3.5 Generate and export
   * Hint button: change color of the N atoms/residues around the hider
   * reveal one hider/reveal all hider button. ask the user to confirm whether to give up, then change the status of one randome hider to "found" (see step 7) and count the number of reveal use
   * dropdown to hide/show/change color of the hider(s) with a "found" status
   * save button to save the state of the game as a pymol session and some state info specific for this game so the user can load/checkpoint any time
   * restart button to restart the game from the initial state
7. The user navigate in the OpenGL viewer and click on the newly generated representation. upon clicking the coordinate within the generated the representaion, the "hider" get a "found" status. Hiders with a "found" status either change in color or becomes hidden 
8. After all the hiders get a "found" status:
   * stop the timer and get the time
   * show a winning message and the time taken for the user to find all hiders


Note 1: Instead of providing own coordinations, also provide several options for demo. Demo PDB should be pre-download citing the source in a doc. The PDB has non-standard residues to increase the challenge of gameplay. 
* Protein Easy: PDB 1znf; Hard: PDB 1xdn
* Nucleic acid: Easy: RNA PDB 5E54, DNA PDB 1K8P; Hard: PDB 2QBZ
* Mixed: PDB 4WB3
* Challenges:
   * Glycoprotein with Glycan: one of the Alpha-1-glycoprotein model from SASBDB (https://www.sasbdb.org) (specify the source and IDs in the doc)
   * Very challenging: Membrane protein from MemProtMD database (https://memprotmd.bioch.ox.ac.uk) with full membrane (dppc-atomistic): 1GZM (helix), 3GP6 (sheets). Theres are large file, remove water and salt (let me do it or agent do it) then compress before we can push them to repo.
