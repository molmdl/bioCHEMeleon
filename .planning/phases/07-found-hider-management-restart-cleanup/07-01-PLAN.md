    registry.py: Add two MODULE-LEVEL functions AFTER the HiderRegistry class

    ```
    # ---- Phase 7 found-hider selection helpers ----

    def build_found_selection(records, object_name):
        """Build a PyMOL selection string for all FOUND hiders.
        Pure (no cmd, no Qt). Returns '<object_name> and id X+Y+Z' for found
        records, or None if no found records. Used by the Game tab dropdown
        (GAME-08) to select found hiders for hide/show/recolor.
        """
        found_ids = [r.id for r in records if r.status == HIDER_STATUS_FOUND]
        if not found_ids:
            return None
        return "%s and id %s" % (object_name, "+".join(str(i) for i in found_ids))

    def group_found_by_rep(records):
        """Return {rep: [ids]} for all FOUND records with rep is not None.
        Pure dict building. Skips rep=None records (post-.pse reload case).
        Used by the Game tab dropdown 'show' mode (per-rep cmd.show).
        """
        out = {}
        for r in records:
            if r.status == HIDER_STATUS_FOUND and r.rep is not None:
                out.setdefault(r.rep, []).append(r.id)
        return out
    ```
    Both are pure (no cmd, no Qt — use HIDER_STATUS_FOUND constant at registry.py:39).
