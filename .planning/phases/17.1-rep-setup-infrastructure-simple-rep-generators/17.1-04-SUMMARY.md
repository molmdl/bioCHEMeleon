## Accomplishments
- `add_hider_reps {molid {tier_specs {{1 VDW}}}}`: one hidden/found rep PAIR per active tier (2N reps) — hidden = tier style + Element coloring + `{resname GAM and beta < 0 and user2 < 1 and user3 <code>}`, found = tier style + ColorID 7 + `{... user2 > 0 and user3 <code>}`; every rep validated by COMBINED-braces read-back string-compare (style vs `[join $sargs " "]`, selection vs the exact built string, index < numreps) — catch never fires on a bad style (P-1). 1-arg default keeps the Phase-16 single-VDW-pair behavior (game.tcl's current call site is unaffected).
- `stamp_tier_codes {molid tier_of}`: numeric user3 tier codes via ONE batched multi-atom atomselect per tier (broadcast; integer-guarded per P7).
- `mark_found_visual {molid idx}`: signature unchanged; sets user2=1 then re-asserts ALL tracked pairs with the STORED literal selection strings (unchanged-string contract), resolving indices via `mol repindex` at use time with `-1`/out-of-range guards (error embeds the resolved value: "is gone (repindex -1)").
- Name-keyed namespace dicts `tier_reps` / `tier_styles` replace `hidden_rep`/`found_rep` (reset per add_hider_reps call); header documents the user3-stamp-BEFORE-add ordering contract (17.1-06 enforces it in start_game).
- 2-tier headless smoke PASS=1 first run; regression smokes on the same staging all green.

## Decisions Made
- **tier_reps/tier_styles RESET per add_hider_reps call** (not merged): the dicts describe the current call's pairs; a prior round's entries would resolve to -1 on the next round's molecule and abort mark_found_visual mid-loop, losing legitimate finds. (Plan said "record"; reset semantics is the correctness-preserving reading — documented in code header.)
- **No compat shims** for the removed hidden_rep/found_rep (per plan): the old contract's readers stay red until 17.1-07.
- **Integer guards on tier codes** (add_hider_reps + stamp_tier_codes): converts VMD's cryptic "bad data in 0th element" (P7) into a clear error; also blocks a nonsense `user3 <code>` selection string from reaching modselect.
- **Smoke mirrors the entry's source order** (…mutation → hiders → game) rather than the plan's dep list verbatim — see deviations.
