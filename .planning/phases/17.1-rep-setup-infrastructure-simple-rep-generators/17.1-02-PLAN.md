<feature>
  <name>Registry per-record rep API (set_rep + assign_reps)</name>
  <files>vmd/lib/registry.tcl, vmd/tests/test_registry.test</files>
  <behavior>
1. `set_rep {idx rep}`:
   - registered idx → sets `_records($idx).rep` to rep (overwrites any prior value, including "").
   - unregistered idx → `error "hider $idx not registered"` (exact wording, matches mark_found).
   - returns nothing.
2. `assign_reps {mapping}`:
   - mapping = dict idx → rep (arbitrary GAME_REPS strings; the proc does NOT validate against GAME_REPS — that is the caller's (rep_tiers/game.tcl) job; the registry stores what it is given).
   - ATOMIC: first validate EVERY key (dict for) — if ANY idx is unregistered, error `hider <idx> not registered` BEFORE touching any record (no partial application).
   - all registered → apply all (set each record's rep), return nothing.
   - empty mapping → no-op.
3. Interaction behaviors:
   - After `reconstruct_from_sentinels <fetch>` (1-arg) + `assign_reps {5 VDW 6 VDW 7 Lines}`, `remaining_by_rep` == `{VDW 2 Lines 2}`-style dicts (e.g. with a fourth hider 8 → Lines) — per-tier counts visible.
   - set_rep AFTER mark_found keeps status ("found") and only changes rep.
   - The 2-arg reconstruct (stamps one rep for all) still works and composes with assign_reps (assign overwrites individual records).

RED test cases (append to test_registry.test, before the marker block; a new `# ---- Phase 17.1 additions ----` section):
- set_rep_sets_field: reconstruct {5} → set_rep 5 Lines → remaining_by_rep == {Lines 1}.
- set_rep_overwrites: reconstruct-with-rep "VDW" {5} → set_rep 5 Lines → remaining_by_rep == {Lines 1}.
- set_rep_unregistered_errors: catch set_rep 999 X → error text exactly `hider 999 not registered`.
- set_rep_keeps_status: reconstruct {5}; mark_found 5; set_rep 5 Lines → status_of 5 == "found" AND remaining_by_rep == {} (found records are not counted as remaining).
- assign_reps_bulk: reconstruct {5 6 7 8}; assign_reps {5 VDW 6 VDW 7 Lines 8 Lines} → remaining_by_rep == {VDW 2 Lines 2}.
- assign_reps_atomic: reconstruct {5 6}; catch assign_reps {5 VDW 999 Lines} → errors `hider 999 not registered` AND rep of 5 is STILL "" (remaining_by_rep == {}).
- assign_reps_empty_noop: reconstruct {5}; assign_reps [dict create] → no error, remaining_by_rep == {}.
- assign_reps_after_mark_found: reconstruct {5 6}; mark_found 5; assign_reps {5 VDW 6 Lines} → remaining_by_rep == {Lines 1}.
- multi_tier_total_consistency: for the bulk case, sum of remaining_by_rep values == count_remaining.
