  <behavior>
Constants (namespace variables, one per line):
- `IMPLEMENTED_TIERS` = `{Lines VDW Licorice CPK Points DynamicBonds}` (GAME_REPS order)
- `TIER_KINDS` = dict: Lines→bonded, VDW→free, Licorice→bonded, CPK→bonded, Points→bonded, DynamicBonds→bonded (Cartoon/NewCartoon/Trace/Tube deliberately ABSENT = not implemented in 17.1)

Procs (all pure; exact signatures):
1. `implemented {rep}` → 1 if rep ∈ IMPLEMENTED_TIERS else 0.
2. `tier_kind {rep}` → "free" | "bonded" | "" (empty for unknown/unimplemented).
3. `style_args {rep}` → the modstyle ARG LIST: DynamicBonds → `{DynamicBonds 1.6}`; other implemented → `[list $rep]`; unknown/unimplemented → `{}`.
4. `scene_reps_to_per_rep {reps_list}` → presence dict {rep 1}. Input = snapshot reps (list of {style sel color material}). Rules: keep style only if `[lsearch -exact $GAME_REPS $style] >= 0` AND `[string first {resname GAM} $sel] < 0`; dedup; output keys in GAME_REPS order. Empty/degenerate input → empty dict.
5. `filter_per_rep_to_scene {per_rep detected}` → copy of per_rep restricted to keys present in detected, GAME_REPS-ordered, counts preserved.
6. `resolve_per_rep {hider_count per_rep detected lock_scene {seed {}}}` → effective per_rep dict. Algorithm (exact):
   a. Clean per_rep: drop non-GAME_REPS keys; drop non-integer or ≤ 0 counts.
   b. allowed = lock_scene truthy ? (keys of detected ∩ IMPLEMENTED_TIERS; if that set is empty → IMPLEMENTED_TIERS) : IMPLEMENTED_TIERS.
   c. Drop per_rep keys not in allowed; then drop-overflow clamp the sum to ≤ hider_count (validate_state semantics: iterate in GAME_REPS order, keep entries that fit, DROP the rest — never truncate to fractional).
   d. If the result is empty → `[::biochemeleon::setup_state::randomize_per_rep $hider_count <allowed-as-list> $seed]`.
   e. Return the dict rebuilt in GAME_REPS order.
7. `tiers_from_per_rep {per_rep}` → list of `{code style count}` triples, GAME_REPS order, counts > 0 only, code = 1-based ordinal WITHIN the active list (e.g. per_rep {VDW 2 Lines 3} → `{{1 Lines 3} {2 VDW 2}}` because Lines precedes VDW in GAME_REPS).
8. `effective_total {per_rep}` → integer sum of counts (0 for empty/invalid).

tcltest cases (RED suite — write ALL before implementing):

- resolve lock_scene=0: empty per_rep → non-empty result, keys ⊆ IMPLEMENTED_TIERS, sum == hider_count, deterministic under a fixed seed (two calls same seed → identical dicts); explicit {VDW 2 Lines 3} kept verbatim; explicit {Cartoon 2} → Cartoon dropped; {VDW 8 Lines 8} hc=10 → {VDW 8} (drop-overflow, keep-that-fits); {Cartoon 4} hc=4 with no implemented keys → randomized across IMPLEMENTED_TIERS.
