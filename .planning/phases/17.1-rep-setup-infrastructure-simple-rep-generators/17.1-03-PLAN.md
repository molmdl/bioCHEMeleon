Key facts (do NOT re-derive — all probe-verified in the simple-generators research):
- Bond law: VMD 1.9.3 bonds two atoms iff `distance < 0.6 × (r_i + r_j)`; radii C 1.70 / N 1.55 / O 1.52 / S 1.80 / P 1.55 / H 1.00 / unknown X 1.50. Verified boundaries: C-C 2.03✓/2.05✗; C-N 1.93✓/1.97✗; C-O 1.91✓/1.95✗; C-S 2.08✓/2.12✗; C-H 1.60✓/1.65✗.
- Distance band: 1.2–1.6 Å (≥0.33 Å margin inside every heavy-anchor cutoff; 2.0 Å is the ceiling with only 0.04 margin — never approach it).
- Overlap rejection: reject a candidate if any real atom OTHER than the anchor is within ~1.4 Å (min_sep; research recommends 1.2–1.6) of it; hider-to-hider separation ≥ 4.0 Å (avoids unintended GAM–GAM cross-bonds — cross-bonding verified at ≤2.0 Å). The per-entry-sep occupied design lets one proc enforce both.
- Coordinate overflow: `%8.3f` maxes at 9999.999; a coordinate ≥ 10000 shifts the whole PDB line right and silently corrupts the element field (probe B). Guard |coord| ≤ 9999.0.
- Extra bonds are NORMAL and blend-positive (a crowded hider may bond 3–5 neighbors) — the bridge asserts numbonds ≥ 1, NEVER == 1. Do not try to prevent extra bonds here.
- Bounded retries with relaxation: "a slightly-clashing hider is better than an infinite loop on 3GP6" (research §3.2).
- Seed convention (generators.tcl header): rand() is the GLOBAL PRNG; seed ONCE at proc top when the optional seed arg is non-empty; production callers pass NO seed. Never reseed per draw.
- Tcl 8.5: no lmap; foreach+lappend; brace ALL expr; `expr {srand($seed)}` pattern.
- geometry constants as namespace variables: D_MIN 1.2, D_MAX 1.6, MIN_SEP_REAL 1.4, MIN_SEP_HIDER 4.0, MAX_COORD 9999.0, MAX_TRIES 25, RELAX_ROUNDS 2.

Constants (namespace vars, one per line): D_MIN 1.2, D_MAX 1.6, MIN_SEP_REAL 1.4, MIN_SEP_HIDER 4.0, MAX_COORD 9999.0, MAX_TRIES 25, RELAX_ROUNDS 2.

1. `sample {lst n {seed {}}}` → n DISTINCT elements of lst (partial Fisher-Yates, port of setup_state::_sample made public). n ≤ 0 → empty; n > llength → all of lst (shuffled). Deterministic under a seed.
2. `unit_vector {{seed {}}}` → {ux uy uz} with norm ≈ 1.0 (±1e-9). Draw 3 uniforms in [-1,1], compute norm; if norm < 1e-6 redraw (bounded ≤ 10 tries) then fall back to {0 0 1}. Deterministic under a seed.
3. `bonded_offset {{seed {}}}` → {dx dy dz} = unit_vector × d where d is drawn uniformly in [D_MIN, D_MAX] inclusive. Length ∈ [1.2, 1.6]. Deterministic under a seed.
4. `reject_overlaps {candidate occupied}` → 1/0. occupied = list of `{x y z sep}` triples. Reject (1) iff ANY entry's distance to candidate is STRICTLY < its sep (distance == sep passes — the strict-< convention matching the bond law). Empty occupied → 0.
5. `place_bonded_hider {anchor occupied {seed {}}}` → {x y z}. anchor = {x y z}. Loop: draw candidate = anchor + bonded_offset; accept iff `reject_overlaps` == 0 AND every |coord| ≤ MAX_COORD. Up to MAX_TRIES draws at full seps; on exhaustion halve ALL seps and retry MAX_TRIES more — RELAX_ROUNDS times; after the last relaxation accept the FINAL drawn candidate with each coord clamped to [-MAX_COORD, MAX_COORD] (termination guaranteed; a slightly-clashing hider beats an infinite loop). Deterministic under a seed.
