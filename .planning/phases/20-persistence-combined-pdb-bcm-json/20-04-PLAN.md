Load-bearing facts (mechanics research — ALL probe-verified):
- Overflow: writepdb formats beta %6.2f; -999 -> "-999.00" overflows the 6-col field -> 79-char line, segid reads GAM, element reads X (radius 1.50). Fix: `$hsel set beta -99.9` -> writepdb -> `$hsel set beta -999` (restore keeps the live molecule's canonical sentinel; skipping the restore is functional but the restore is PINNED — AGENTS.md documents beta=-999 as the sentinel constant). -99.9 reloads as -99.9000015258789 (float32) — still < 0, idempotent across repeated saves.
- Selector: `resname GAM and beta < 0` (NEVER beta == -999). Residue rounds: only CAs carry -999 — the same selector + clamp covers them (probe z8).
- Zip create: `exec tar --format zip -c -f <out.bcmz> -C <staging> game.pdb game.bcm` — rc=0, PK magic 504b0304, DEFLATE, flat members, overwrites. TRAPS: `tar -a` writes ustar (magic 67616d65) — forbidden; absolute member paths strip the drive letter, rc=1, directory-tree members — always -C + bare names.
- Zip read: `exec tar -xf <x.bcmz> -C <dir>` — rc=0, overwrites, format auto-detected, reads tar/pwsh/own zips too. Corrupt input -> rc=1 "Unrecognized archive format" (trust the rc, not the listing).
- Atomicity: zip to `<final>.part` in the SAME dir as final (tar -f can land anywhere) then `file rename -force` (probe: overwrite works). Crash leaves an old .bcmz or a .part orphan.
- PK gate: read the first 4 bytes, `binary scan $d H8 magic` -> "504b0304". (Counted `binary format` takes ONE list arg; nested parens in expr subscripts fail — pitfall 6/7 — not needed here but do not reintroduce.)
- Staging dirs: `file tempfile` does NOT exist in Tcl 8.5 — use `[file join $::env(TEMP) bchm_[clock clicks]]` + file mkdir / file delete -force.
- Module placement: STANDALONE mol bridge like backup.tcl (sources NOTHING; reads mutation constants via the ::biochemeleon::mutation:: namespace at call time; NEVER sources registry.tcl — re-sourcing wipes _records). Sourced by the entry after mutation.tcl, before game.tcl (20-10 wires the line).
- Tcl 8.5 only; brace all expr; catch + error for the gates; list-form exec (never string exec — space-safe).
