<gap_diagnosis>

### Gap 1 — Cap not enforced (Test 2 item 2 FAILED)
**Root cause:** `current_target_object()` (gui_setup.py:251-263) does `name in list_loaded_molecule_objects()` — a re-query that returns `None` unless the combo text exactly matches PyMOL's `cmd.get_names` output. When it returns `None`, `_on_target_changed` (line 184) bails out before `cmd.count_atoms` runs, so `hider_spin.setMaximum(...)` never fires and the cap stays at 50.
**Fix:** `current_target_object()` returns the non-empty combo text in loaded mode (drop the membership re-query); the existing try/except in `_on_target_changed` handles a bogus name. Cap recomputes on selection.

### Gap 2 — per-rep sum can exceed total hider_count
**Root cause:** per-rep spinboxes are `setRange(0, 999)` (gui_setup.py:124); nothing enforces `sum(per_rep) <= hider_count`. `validate_state` drops zeros but doesn't bound the sum.
**Fix (pure):** `validate_state` truncates per_rep so `sum <= hider_count` (keep entries in insertion order, drop any that exceed the remaining budget).
**Fix (UI):** `_recompute_per_rep_maxes()` sets each per-rep spinbox's `setMaximum(max(0, hider_count - sum(other per_rep values)))` on `hider_spin.valueChanged` + each per-rep `valueChanged`.

### Gap 3 — randomize changes source + can produce empty boxes
**Root cause:** `randomize_state` (setup_state.py:88) picks `mode = rng.choice(["loaded","fetch","demo","demo"])` and always sets `selected_object=""`, `pdb_code=""`. Randomize can switch the user's chosen source, land on fetch with an empty pdb_code, or land on loaded with an empty combo.
**Fix:** Add `lock_source` checkbox in the Target group. When checked, `_randomize` preserves `target_mode` + the relevant identifier and only randomizes hider composition. `randomize_state` gains `lock_source` + `locked_state` params.

### Gap 4 — randomize fetch mode leaves pdb_code empty
**Root cause:** `randomize_state` sets `pdb_code=""` for fetch mode to empty box.
**Fix:** Add a user-editable PDB-pool text area (in the fetch page of the QStackedWidget, 34 curated mixed PDB codes). `randomize_state` gains a `pdb_pool` param: when it picks fetch mode and pool is non-empty -> pick a random code from the pool; when pool is empty -> re-roll to demo (never produce empty fetch box).

</gap_diagnosis>

           """Lowercase, strip, keep only 3-5 char alphanumeric; else empty string."""
           if not code:

           c = str(code).strip().lower()
           if 3 <= len(c) <= 5 and c.isalnum():

       def _validate_pdb_pool(pool):
           """Validate a PDB pool: lowercase, 4-char alnum, dedupe, bound to 100.

           if not isinstance(pool, list):

               # PDB_POOL convention is 4-char; accept 3-5 for robustness
               if c and c not in seen_set and len(c) == 4:
                   seen.append(c)
                   seen_set.add(c)
                   if len(seen) >= 100:
                       break
           if not seen:
               return list(PDB_POOL)
           return seen
