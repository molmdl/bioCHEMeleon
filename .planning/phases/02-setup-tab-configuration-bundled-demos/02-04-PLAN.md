  <name>Windows PyMOL smoke test — 4 Phase-2 success criteria</name>
  <what-built>
    The complete Phase-2 pre-game configuration experience:
    - demos.py: to_windows_path (WSL→Windows path), list_loaded_molecule_objects, fetch_pdb, get_active_reps (rep <name> selector), load_demo (bundled PDB loader)
    - setup_state.py: DEFAULTS, GAME_REPS, DEMO_MANIFEST, hider_count_cap, randomize_state, validate_state (pure, unit-tested)
    - gui_setup.py: full SetupTab with 3-mode target selector (loaded/fetch/demo), hider-count spinbox (capped), lock-scene checkbox (auto-detects reps), per-rep hider rows (5 reps), difficulty toggle, 4 action buttons (Reset/Randomize/Save/Load)
    - 6 bundled demo PDBs (1znf, 1xdn, 5e54, 1k8p, 2qbz, 4wb3) + SOURCES.md citations
  </what-built>

  <how-to-verify>
    **Prerequisites:**
    1. Copy the updated `biochemeleon/` package to the PyMOL plugin directory (or use the Phase-1 install workflow: copy to `tmp/` + Plugin Manager install). The `data/demos/` subdirectory with the 6 PDBs + SOURCES.md must come along.
    2. Launch Windows PyMOL via `setenv.bat` (double-click or `cmd.exe /c setenv.bat && pymol`).
    3. Load the bioCHEMeleon plugin via Plugin Manager (or it auto-loads if installed in the startup dir).
    4. Open the plugin: Plugins → bioCHEMeleon. The dialog opens with 2 tabs (Setup, Game status).

    **Test 1 — Success Criterion 1: Object selector (loaded object / PDB fetch / bundled demo)**
    1. Go to the Setup tab. Confirm the form is populated (NOT the "coming in Phase 2" placeholder).
    2. In the "Target" group, the "Source:" dropdown has 3 options: "Loaded object", "Fetch from PDB", "Bundled demo".
    3. Switch to "Loaded object" — confirm a combobox + refresh button appears below. Load a PDB via PyMOL's File → Open (e.g. any PDB you have). Click the combobox dropdown — confirm the loaded object appears. Click the refresh button — confirm it refreshes.
    4. Switch to "Fetch from PDB" — confirm a text field + "Fetch" button appears. Type a PDB code (e.g. `1ubq`) and click Fetch. **(Requires network — skip with a note if offline. The success criterion only requires the fetch MODE to exist and render its widget; the actual network fetch is a bonus check.)** If online, confirm the structure loads into the viewer.
    5. Switch to "Bundled demo" — confirm a combobox appears listing all 6 demos, formatted as "Category — ID (difficulty)" (e.g. "Protein — 1znf (easy)", "Mixed — 4wb3 (mixed)"). Confirm all 6 are present: 1znf, 1xdn, 5e54, 1k8p, 2qbz, 4wb3.

    **Test 2 — Success Criterion 2: Hider count, lock scene, per-rep counts, difficulty**
    1. Load a demo (e.g. switch to "Bundled demo" → select "Protein — 1znf (easy)"). Note: the demo combo just SELECTS the demo; to actually load it into the viewer, you may need to use PyMOL's File → Open on `biochemeleon/data/demos/1znf.pdb` first (the Setup form's demo combo sets the *target selection*, not the load action — loading happens at game Start in Phase 4). Alternatively, load 1znf via File → Open, then switch to "Loaded object" mode and select it from the combobox.
    2. With a loaded object selected (e.g. 1znf, ~212 atoms), confirm the "Hider count" spinbox max is capped (e.g. max ~4 for 212 atoms — the spinbox physically can't exceed the cap). Try scrolling up — it should stop at the cap.
    3. In PyMOL's command line, run `show cartoon, 1znf` to display the cartoon representation on the object.
    4. Tick "Lock current scene" — confirm the per-rep checkboxes auto-populate: the "cartoon" checkbox should auto-tick and become LOCKED (greyed out — can't uncheck). Other rep checkboxes should be unchecked and also locked. **This confirms the `rep <name>` selector works on your PyMOL build (research §12.1 — the MEDIUM-confidence open question).**
    5. Untick "Lock current scene" — confirm all 5 rep checkboxes become UNLOCKED (editable). Tick 2 reps (e.g. "spheres" and "cartoon"). Confirm a spinbox appears/enables next to each ticked rep. Set spheres=3 and cartoon=2. Confirm the "random" label disappears when a rep is ticked.
    6. Toggle the "Easy: show remaining hiders per representation" checkbox — confirm it toggles on/off.

    **Test 3 — Success Criterion 3: Reset / Randomize / Save / Load**
    1. Click "Reset" — confirm ALL widgets return to defaults (mode=Loaded object, hider count=10, lock scene=unchecked, all per-rep unchecked, difficulty=easy).
    2. Click "Randomize" — confirm the form changes to random valid values (random mode, random demo, random hider count within cap, random per-rep subset, random lock/difficulty). Click it again — confirm different values each time.
    3. Click "Save Setup…" — a file dialog opens. Pick a location and save. Confirm a `.bcm.setup.json` file is written. Open it in a text editor — confirm it's valid JSON with fields: format, target_mode, selected_object, pdb_code, demo_id, hider_count, lock_scene, per_rep, difficulty_easy.
    4. Change some form values (e.g. set hider count to a different number, tick a rep). Click "Load Setup…" — pick the file you just saved. Confirm the form repopulates to the saved state.

    **Test 4 — Success Criterion 4: Bundled demos load + render with sources cited**
    1. In the PyMOL command line, run:
       ```
       load C:\Users\nglok\Desktop\WORKDIR\molmdl\bioCHEMeleon\biochemeleon\data\demos\1znf.pdb
       ```
       (Adjust the path to your repo location. Or use File → Open and navigate to `biochemeleon/data/demos/`.)
       Confirm the 1znf structure loads and renders in the 3D viewer.
    2. Repeat for each of the 6 demos: 1znf, 1xdn, 5e54, 1k8p, 2qbz, 4wb3. Confirm each loads and renders (you should see atoms/bonds/cartoon in the 3D view).
    3. **(Tests `load_demo` end-to-end)** In the PyMOL Python console (or a `run` of a one-liner), execute: `from biochemeleon.demos import load_demo; print(load_demo('1znf'))` — confirm it prints `1znf` (the object name) and the 1znf structure appears in the viewer (and the object list). This exercises the bundled-loader path (`to_windows_path` + `__file__`-relative resolution + `cmd.load`) that the Setup form's demo mode relies on at game Start (Phase 4). Keep this as an ADDITIONAL step — do NOT remove the native-load baseline above (it's the baseline that confirms the PDB files themselves are valid; this step confirms the code path the form actually uses).
    4. Open `biochemeleon/data/demos/SOURCES.md` in a text editor. Confirm all 6 demos are cited with: PDB ID, DOI, title, authors, publication (journal + vol/pp + year + PMID), and method.
    5. **Verify the modeless behavior:** with the plugin dialog open, confirm the 3D viewer is still interactive (you can rotate/zoom the molecule while the dialog is open — no blocking).

    **Expected PASS for each test:**
    | Test | Criterion | PASS when |
    |------|-----------|-----------|
    | 1 | Object selector | All 3 modes render their widget; demo combo lists all 6; fetch loads (if online) |
    | 2 | Hider config | Cap visible; lock-scene auto-detects reps (cartoon auto-ticks); per-rep counts settable; difficulty toggles |
    | 3 | Buttons | Reset→defaults; Randomize→valid random; Save→valid JSON; Load→repopulates form |
    | 4 | Demos + sources | All 6 PDBs load+render via native `load`; `load_demo('1znf')` prints `1znf` + renders (bundled-loader path); SOURCES.md has all 6 citations; dialog stays modeless |
  </how-to-verify>
