    # Plain core-Tk menubutton (the setup_tab loaded-mol/demo idiom) -- NOT
    # ttk::menubutton (unexercised) and NOT ttk::combobox (banned 18-06).
    # Stateless action entries: no placeholder, no index-reset dance (the
    # v1 QComboBox artifact does not apply to menus). Entries stay enabled
    # in every game state; the silent no-op guards (no round / zero found)
    # live in the dialog-scope handler (plan 19-10). Found-mgmt filters by
    # STATUS -- all found hiders globally; no per-index listing exists.
    menubutton $help.found -text "Found hiders" -relief raised -bd 2 \
        -direction flush -menu $help.found.menu
    menu $help.found.menu -tearoff no
    $help.found.menu add command -label "Hide found" \
        -command [list ::biochemeleon::on_found_mgmt hide]
    $help.found.menu add command -label "Show found" \
        -command [list ::biochemeleon::on_found_mgmt show]
    $help.found.menu add command -label "Recolor found" \
        -command [list ::biochemeleon::on_found_mgmt recolor]
    pack $help.found -side left -padx 4
```

    # -- Found-color palette menubutton (DIFF-04, Phase 19) -----------------
    # The palette vocabulary is setup_state::GAME_FOUND_COLORS (19-03) --
    # flat {name id} pairs, default green 7 FIRST, orange 3 deliberately
    # excluded (it is the hint-highlight color). Named entries are the
    # accessibility point: color-blind players choose by LABEL, never by
    # judging a hue. tk_chooseColor is REJECTED for Phase 19 (locked
    # decision) -- do not add it, not even as a "More..." entry. Selection
    # dispatches to the dialog-scope handler (plan 19-10) which calls
    # hiders::set_found_color: existing found reps recolor immediately and
    # future finds inherit via the found_colorid preference. The choice
    # PERSISTS across rounds/restarts/cleanup (v1 _found_color parity);
    # it is game-session state, NOT setup form state -- no persistence
    # code lives here. The optional menubutton swatch tint is deferred
    # (research 7.8 -- named labels alone satisfy the intent).
    menubutton $help.color -text "Color" -relief raised -bd 2 \
        -direction flush -menu $help.color.menu
    menu $help.color.menu -tearoff no
    foreach {cname cid} $::biochemeleon::setup_state::GAME_FOUND_COLORS {
        set lbl "[string toupper [string index $cname 0]][string range $cname 1 end]"
        $help.color.menu add command -label $lbl \
            -command [list ::biochemeleon::on_found_color $cid]
    }
    pack $help.color -side left -padx 4
```
2. Menu order = constant list order (green first). Entry labels are the capitalized names (Green / Red / Yellow / Cyan / Pink / Purple / White for the pinned vocabulary). The `[list ...]` form pins the colorid VALUE per entry at build time.
