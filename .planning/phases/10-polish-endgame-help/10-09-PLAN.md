  <how-to-verify>
Open the plugin in a real Windows PyMOL session (via `setenv.bat` → `pymol`, then Plugins → bioCHEMeleon). Run these 8 checks IN ORDER. For each, record PASS or describe the issue. If any check fails, note which plan addresses it (do NOT fix it here — describe + return).

**Check 1 — Win dialog stats (SC3 / DIFF-02).** Start a fresh game (Setup tab: pick a bundled demo e.g. 1znf, hider count ~5, check spheres + cartoon, difficulty easy, press Start). Play to win by clicking hiders (use Hint/Reveal if needed, but for the 0/0 flex case, play a SECOND round without using Hint or Reveal). On win:
   - The win dialog headline shows the hider count (e.g. "You found all 5 hiders in 1:23!").
   - Below the headline, three stats: Time, Hints used, Reveals used.
   - For the 0/0 flex round: "Hints used: 0" and "Reveals used: 0" are shown (NOT hidden).
   PASS if all three stats + hider count appear. FAIL → Plan 10-05.

**Check 2 — Debrief dialog + hiders shown (SC4 / DIFF-03).** After dismissing the win dialog (Check 1):
   - A SECOND modal dialog appears titled "Debrief" with the headline "Debrief — where they were hiding".
   - Behind the dialog, in the viewer, ALL hiders are now visible in their own reps (spheres as spheres, cartoon as cartoon, etc.) — even if you used "Hide found" mid-game.
   - The debrief dialog shows per-rep explanations matching the reps in the game (e.g. if the game had spheres + cartoon, you see bullets for "spheres: N hider(s)" and "cartoon: N hider(s)" with the domain-accurate explanations).
   PASS if the debrief dialog appears + hiders visible + explanations match the game's reps. FAIL → Plan 10-06.

**Check 3 — Per-rep explanations accuracy (SC4).** Read the debrief explanations:
   - spheres explanation mentions "single pseudoatom" / "matching element, color, and radius".
   - cartoon explanation mentions "COPIED real backbone segment" / "kink".
   - (If the game had other reps, spot-check their explanations too.)
   PASS if the explanations match the domain-accurate text from the research (no invented science, student-friendly). FAIL → Plan 10-01 (the DEBRIEF_EXPLANATIONS text).

**Check 4 — Cleanup after debrief (DIFF-03 cleanup gate).** Dismiss the debrief dialog:
   - For a FRESH (non-imported) game: the viewer returns to the pre-game state (hiders vanish, original colors restored). The debrief highlight was temporary.
   - For an IMPORTED game (Import a .bcmz puzzle, play to win): after the debrief dismiss, the hiders STAY (all found+green). Click the Cleanup button on the Setup tab → the two-step restore removes them.
   Test BOTH paths if time permits; at minimum test the fresh-game path. PASS if the fresh-game cleanup runs + viewer returns to pre-game. FAIL → Plan 10-06 (the _is_imported gate / cleanup move).

**Check 5 — Setup + Game tooltips render (SC1 / UX-01).** Hover (don't click) over ~5 widgets on the Setup tab (e.g. the Source combo, a per-rep checkbox, the Start button, the hider count spin, the lock-source checkbox) and ~5 on the Game tab (Hint, Reveal one, the found-mgmt combo, the timer label, the reveal label):
   - Each shows a tooltip on hover with clear, concise, student-friendly text.
   - The per-rep checkbox tooltip includes the rep explanation (e.g. hovering the "cartoon" checkbox shows the cartoon explanation, not just "Check to put hiders in this rep").
   PASS if all 10 spot-checked widgets show tooltips with the right text. FAIL → Plan 10-02 (Setup) or 10-07 (Game).

**Check 6 — Help dialog (SC1 / UX-01 + SC2 / UX-02).** Click the Help button (below the tabs, right-aligned):
   - A MODAL dialog opens ("bioCHEMeleon — Help").
   - It contains all 6 sections: What is bioCHEMeleon, Setup tab, Game tab, Representations explained, PyMOL controls, Tips — switch reps.
   - The text scrolls (it's longer than the viewport).
   - Dismiss with the OK button (or Esc) — returns focus to the main dialog.
   - Open Help from BOTH the Setup tab and the Game tab (the button is below the tabs so reachable from both).
   PASS if all 6 sections present + scrolls + dismisses. FAIL → Plan 10-03.

**Check 7 — PyMOL controls accuracy, esp. wheel=slab gotcha (SC2 / UX-02 — the 30-second real-PyMOL check).** This is the critical verified claim. With a molecule loaded:
   - Scroll the PLAIN scroll wheel (no modifier) → confirm it adjusts the CLIPPING SLAB (the near/far clipping planes move; the molecule may get clipped/sliced, NOT zoom in/out). This is the counterintuitive PyMOL gotcha the Help text calls out.
   - Hold Ctrl + scroll → confirm this ZOOMS (the molecule grows/shrinks).
   - Right-drag → confirm this also zooms (move toward/away).
   - Left-drag → confirm this ROTATES (not picks — a drag is distinct from a click).
   - Single Left-click an atom (during a game, with the PickWizard active) → confirm it picks (checks if it's a hider).
   PASS if the wheel=slab gotcha is accurate (plain wheel = clipping, NOT zoom) AND Right-drag/Ctrl+wheel = zoom AND Left-drag = rotate AND Left-click = pick. If the plain wheel ZOOMS in the real PyMOL build (conda build default differs from open-source), the Help text in Plan 10-03 needs adjusting to match the observed behavior — note this as an issue. FAIL (wheel zooms) → Plan 10-03 (adjust HELP_HTML controls text to match observed behavior).

**Check 8 — Reps explained match GAME_REPS (SC1).** In the Help dialog's "Representations explained" section + the per-rep tooltips:
   - All 5 reps appear: lines, sticks, spheres, cartoon, ribbon.
   - surface is NOT listed (out of scope).
   PASS if all 5 + no surface. FAIL → Plan 10-02 (tooltips) or 10-03 (Help).
