## Decisions Made
- **Frame-0 read pinning in make_residue_hiders; unpinned writepdb kept.** Multi-model demos (1znf ships 2 frames) make unpinned coordinate reads racy (dbg_pin: the current frame even DRIFTS -- `molinfo set frame` does NOT pin it), which produced mixed-frame records and broken junctions (smoke run 1). Pinning every read to frame 0 fixed the residue tier; an interim write-pin was REVERTED because the byte-frozen bonded tier reads unpinned and phase17_bonded_smoke regressed (2.2 A anchors, numbonds 0). Caller contract: pass single-frame molecules; the game-flow collapse belongs to 17.2-09's dispatch.
- **Rear-junction sign safety in the bridge.** splice::displacement is perpendicular to the FORWARD peptide bond only; its projection on the REAR bond vector (prev C -> anchor N) can stretch that junction past the 1.95 A C-N cutoff AT 1.0 A (run 6: junction_n unbonded). The bridge flips the sign when the rear projection is positive: the forward junction is sign-invariant (exactly sqrt(1.33^2+1)=1.66 A), the flipped rear can only shorten (<= 1.66 A).
- **Smoke positive control = junction bonds + fake bits + bond scene-diff; window comparisons demoted to prints.** The cartoon window is STRIDE-shift-variant: inserting the fake into a helix run splits it and the window can crash below the control (22->6 observed, run 20) with zero pathology; probe6 had already documented "the direct CA->CA segment count dropped". The bond scene-diff (A=all vs B=not resname GAM, cylinder delta >= 4/fake) is ss-independent and observed at 70/80/72 vs floors 36/40.
- **Chain-G (Pitfall C8) falsified and documented in-smoke.** The research's assumed fragment-homogeneity failure mode does not exist in VMD: distance bonds ignore chain ids, so a chain-G fake bonds into the chain, renders its 6 GAME-only bits, and shifts the fragment's STRIDE exactly like a chain-A fake. The smoke asserts the verified facts (bits >= 1, a junction forms across the chain mismatch) and prints the window as variance-only.
- **2.0 A negative control = junction loss + real-window <= control.** At 2.0 A the forward junction is exactly 2.40 A (broken); with the sign flip the rear may survive (half-bonded) or not -- the smoke asserts AT LEAST ONE junction lost (resid-scoped) and the real window <= control, both stable across draws (window 30<=30, 24<=24, 16<=22, 3<=18 observed).

## Issues Encountered
- **VMD multi-frame raciness (NEW discovery, pinned):** on 2-frame 1znf, unpinned atomselect coordinate reads land on whatever frame is current at read time and the current frame DRIFTS (dbg_pin: `molinfo get frame` returned 1 -> 3 -> 5 across commands; `molinfo set frame` does not pin). Only `$sel frame 0` before reads (and a frame-0-pinned writepdb) is deterministic. This affects EVERY future smoke touching multi-model demos -- hence _load_demo_1f in the harness.
- **Rear-junction displacement hazard (NEW discovery, pinned):** the research's envelope math covered only the FORWARD junction (the one d is perpendicular to). The rear junction's distance includes 2*1.33*d*cos(projection) and can exceed the 1.95 A cutoff at d=1.0 for turn-region anchors. The bridge's sign flip makes both junctions <= 1.66 A for every mid-chain anchor.
- **tclsh unavailable in this WSL session** (17.2-01 precedent): the pure-layer load check ran under the headless-VMD smoke instead.
- **VMD startup ~2 min per run:** every staged run used timeout >= 330 s (25 smoke runs + 4 regression runs + 8 debug probes this session).
- **phase17_capstone_smoke sub-case C now fails (PRE-EXISTING, verified at HEAD with my changes stashed):** 17.2-03's seam widening made tier_kind(Cartoon)="residue", so the dispatch's "no generator yet" drop-check no longer drops Cartoon (per_rep keeps {VDW 1 Cartoon 2}, effective total 3, reps +4). game.tcl does NOT call make_residue_hiders yet (grep-verified; the placement loop handles only free/bonded). NOT caused by 17.2-04; the dispatch plan (17.2-09) owns the wiring and the capstone's obsolete under-generation sub-case needs a gap-closure update (IMPLEMENTED_TIERS == GAME_REPS now -- no unimplemented rep exists to exercise that path).
- **VMD `within` swallows trailing expressions:** `within 2.0 of index N and not index N` parses as within-of-an-empty-selection -> 0 hits (diagnostic run proved the atom sat at 1.0004 A). Parenthesize the reference. NOTE: the byte-frozen make_bonded_hiders uses this exact unparenthesized pattern (`within 3.0 of index $aid and not index $aid`) -- its occupied-neighborhood list is silently empty; 17.1 smokes stay green because placement rejection is probabilistic. Flagged for a future hygiene pass, NOT touched here (byte-identical mandate).
