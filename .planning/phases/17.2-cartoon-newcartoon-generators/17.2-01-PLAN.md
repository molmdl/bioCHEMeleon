Key facts (do NOT re-derive — all probe-verified in 17.2-RESEARCH):
- **Displacement envelope (the governing math):** VMD bonds iff `d < 0.6×(r_i+r_j)`; peptide junction real 1.33 Å, C–N cutoff 1.95 Å → survives rigid displacement d perpendicular to it while `sqrt(1.33² + d²) < 1.95`, i.e. **d < 1.43 Å**. Probed: 1.0 Å safe + in-path (PP10/SX10), 1.44 Å broken/degraded (SX14/PP14), along-bond breaks at 0.62 Å. **1.0 Å ⊥ peptide bond is THE design constant** (research §4.1/§10.1).
- **Direction rule (Pitfall C4):** the perpendicular is to the PEPTIDE-BOND vector `unit(N_next − C_anchor)`, NOT to the CA–CA axis (probe4 DIRPP failed at 1.0 Å ⊥ axis while PP10 succeeded ⊥ bond).
- **Record spec (probe-exact, research §10.1):** 78-col ATOM lines, format string = mutation.tcl `_hider_record`'s; resname GAM cols 18-20; chain = ANCHOR's chain (col 22 — NOT "G"); resid 9001+k (cols 23-26); occupancy 1.00; **beta -999.0 on CA ONLY, 0.00 on N/C/O/CB** (%6.1f — "-999.0" fits, NEVER %6.2f); segid GAME all atoms (cols 73-76); element N/C/C/O/C per atom ALWAYS emitted (cols 77-78); coords = anchor coords + (dx,dy,dz).
- **No CONECT, no TER insertion, no renumbering** — the distance search bonds both junctions at ≤1.0 Å (research §4.2).
- **Coordinate overflow guard:** `%8.3f` corrupts at |coord| ≥ 10000 — guard |coord| ≤ 9999.0 AFTER translation (17.1-RESEARCH-simple-generators probe B).
- **Anchor separation:** distinct anchors; MIN_ANCHOR_SEP 5.0 Å between chosen CAs (two 1.0 Å displacements can approach by ≤2.0 Å; 5.0 − 2.0 = 3.0 > 1.95 worst-case cutoff → no fake-fake bonds; adjacent real CAs are ~3.8 Å apart, so 5.0 also prevents abutting bumps).

Constants (namespace vars, one per line):
- `SPLICE_DISPLACEMENT` 1.0 (Å; the probe-proven in-path sweet spot; hard envelope 1.43)
- `RESID_BASE` 9001 (disjoint fake-resid block; real demo resids ≤ ~500)
- `MIN_ANCHOR_SEP` 5.0 (Å, pairwise CA separation)

Procs (all pure; exact signatures):
1. `perp_vector {u {ref1 {0.0 0.0 1.0}} {ref2 {1.0 0.0 0.0}} {ref3 {}}}` → {ux uy uz} unit vector ⊥ u. Norm-check u first (norm < 1e-6 → `error "splice::perp_vector: degenerate peptide-bond vector (zero length)"`). Ladder: v = cross(u, ref1); if |v| ≥ 1e-6 → return unit(v); else ref2; else ref3 if non-empty; else `error "splice::perp_vector: no non-parallel reference for the ladder"`. Deterministic (no randomness, no sign flip).
2. `displacement {c_pt n_pt {ca_fallback {}}}` → {dx dy dz} = SPLICE_DISPLACEMENT × perp_vector(unit(n_pt − c_pt)). If |n_pt − c_pt| < 1e-6 (degenerate bond vector) AND ca_fallback is a non-empty 3-vector → use unit(ca_fallback) as the bond direction instead (the research's degenerate-parallel fallback, flagged); if ca_fallback empty → propagate perp_vector's error.
3. `resid_block {n {start {}} {real_max 0}}` → list start..start+n−1 (start defaults RESID_BASE). Guard: start ≤ real_max → `error "splice::resid_block: resid block not disjoint from real resids (block start <start>, real max <real_max>)"`. n ≤ 0 → empty.
4. `select_anchors {candidates n {seed {}}}` → chosen list. candidates = list of `{key ok ca_x ca_y ca_z}` descriptors (ok precomputed by the bridge: mid-chain + occupied-clear + valid chain). Algorithm: eligible = ok-true candidates; cap n at llength(eligible); shuffled = generators::sample $eligible $n (seed convention); greedy acceptance in shuffled order: accept iff CA distance to every ALREADY-ACCEPTED candidate ≥ MIN_ANCHOR_SEP (squared comparison, eps 1e-9); stop at n accepted or eligible exhausted; return the accepted FULL descriptors in acceptance order (may be < n — under-generation tolerance; caller uses actual count).
5. `assemble_record {atoms_data chain resid displacement {max_coord 9999.0}}` → `{chain resid atoms_displaced}`. atoms_data = list of `{name element x y z}` (the anchor's present subset in N/CA/C/O/CB order). Validation errors (exact prefixes): < 4 atoms → `error "splice::assemble_record: fake residue needs N/CA/C/O (got <k> atoms)"`; names[0] ne "N" or names[1] ne "CA" → `error "splice::assemble_record: atom order must be N-first, CA-second (got <n0>,<n1>)"`; no atom named O → `error "splice::assemble_record: fake residue needs an O atom"`; any coord not a double → error; AFTER applying displacement to EVERY atom (rigid translation): any |coord| > max_coord → `error "splice::assemble_record: coordinate overflow |<v>| > <max_coord> after displacement (%8.3f corrupts)"`. Success: every atom coord = original + displacement (exact float add).
6. `atom_record {serial name element chain resid x y z}` → the 78-char ATOM line. Format string (VERBATIM copy of mutation.tcl `_hider_record`'s, comment cross-references it — both probe-pinned): `ATOM  %5d %4s%1s%-3s %1s%4d%1s   %8.3f%8.3f%8.3f%6.2f%6.1f      %-4s%2s` with args serial, name, " ", SPLICE_RESNAME, chain, resid, " ", x, y, z, 1.00, beta, SPLICE_SEGID, element. **Beta policy (baked in): name eq "CA" → -999.0 (via %6.1f → "-999.0"); else 0.00.** altloc/icode are spaces.
