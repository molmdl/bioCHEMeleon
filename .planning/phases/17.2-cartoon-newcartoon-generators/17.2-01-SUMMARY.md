## Decisions Made
- **Option A (ss rendering)** accepted and recorded durably in the module header: no ss='L' in VMD (structure = T/C/H/G/E/B); spliced GAM gets T from load-time STRIDE → smooth coil/turn tube (v1-accepted 2026-08-16); `ssrecalc` UNNECESSARY + DESTRUCTIVE — NEVER in the generation flow (Pitfall C2); manual `set structure` override exists but single-residue hiders render as tube regardless (≥3-residue helix rule) → force-SS variant OUT OF SCOPE; Trace/Tube are sibling consumers, not a sidestep.
- **Beta rendering**: pre-render the 6-char beta field (CA `%6.1f` → "-999.0"; others `%6.2f` → "  0.00") and slot with `%6s`. The plan's single-`%6.1f` sketch cannot satisfy the committed `atom_record_ca_beta` expectation ("  0.00" for N) while keeping "-999.0" overflow-safe; CA output stays byte-identical to `_hider_record`.
- **Validation order in assemble_record**: order-check → O-check → count-check. The committed `assemble_missing_o` case passes 3 atoms `{N CA C}` and demands the "needs an O" message; a count-first order would emit "needs N/CA/C/O (got 3 atoms)" and fail.
- **Header hygiene**: comments avoid the literal tokens `mol `, `atomselect`, `tk` so the purity grep gate returns zero hits including comments (ssrecalc prohibition worded without the `mol ` prefix; the `ssrecalc` grep still matches).

**1. [Rule 3 - Blocking] Sibling source failed under `vmd -e`: [info script] empty + VMD source silently skips missing files**
- **Found during:** Task 2 (GREEN) — first staged run Failed=6, all select_anchors cases erroring `invalid command name "::biochemeleon::generators::sample"`
- **Issue:** The plan's `source [file join [file dirname [info script]] generators.tcl]` no-ops under `vmd -e`: [info script] is EMPTY even inside sourced files (probed with dbg.tcl), and VMD's source wrapper silently skips missing files (so `./generators.tcl` was skipped without error). mutation.tcl gets away with the idiom only because it is loaded via real source chains.
- **Fix:** Resolve the sibling dir explicitly: try `[file dirname [info script]]`; if generators.tcl is not there, fall back to `[pwd]/vmd/lib` (the harness layout); if still missing, `error` loudly instead of relying on VMD's silent skip.
