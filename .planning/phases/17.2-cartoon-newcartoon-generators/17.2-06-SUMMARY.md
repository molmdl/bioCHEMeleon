## Decisions Made
- **Assertion reads nstrip, not nstri** (Rule 1, fixed in first run): `_parse_dat` returns `{nsph ncyl nstri nstrip cols}` where nstri=STri and nstrip=TriStrip; the first run bailed "TriStrip got=0" while the log showed nstrip=42 -- the mesh HAD rendered, the check read the wrong token. Same class fix applied to the window totals (TriStrip+FCyl).
- **Option-A structure property over the plan-pinned `== T`:** the plan truth pins "structure == T", but the committed 17.2-04 discovery (splice smoke comments) is that the letter is ANCHOR-DEPENDENT (STRIDE reads the displaced phi/psi; PRNG-chosen coil anchors read C). The smoke asserts T-or-C (both render the smooth coil/turn tube; FAIL on H/G/E/B/blank) and prints the letters (observed {T T C} and {T C C}). Zero ssrecalc anywhere (load-time STRIDE only). Documented per the plan-conflict rule.
- **GAM count derived, not hardcoded 15:** a GLY anchor yields a 4-atom residue; expected = sum of record atom counts (observed 15 and 14 across runs; plan's 15 is the 3x5 non-GLY case).
- **Window exceedance = evidence prints, scene-diff = assertion:** plan-pinned "window > control" conflicts with the settled STRIDE-shift-variance discovery (17.2-04 run-20: 22->6 with zero pathology). Observed here: spliced 70 vs control 70 (equal) in run 1; the comparison printed as a NOTE. The asserted positive control is the bond scene-diff (A=all vs B=not resname GAM, Lines probe, delta >= 4/fake floor) + GAME-only TriStrip >= 1 + scoped junction bonds.
- **Chained hider accumulation for 3 records:** one make_residue_hiders call for 3 under-generates on compact 1znf (greedy 5.0 A CA separation); the smoke loops with need=remaining, occupied_hiders=fake CA positions so far, resid_start=9001+got -- the lib's multi-call pattern, keeping resids {9001 9002 9003} distinct.
- **Rep-clobber repair via mark_found_visual:** _render_bits restores earlier reps to "all", which would clobber the hider pairs' selections; the plan's step order (renders, then found-marking) makes mark_found_visual's mandatory re-evaluation re-assert exactly repair them -- read-back re-proven post-assert.
