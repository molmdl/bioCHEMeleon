## Decisions Made
- **File-layout slicing walk instead of plain GAME_REPS-order cumulative slicing.** The plan's cumulative-index-count rule is only correct when the tier order coincides with the file order (all simple tiers before all residue tiers in GAME_REPS order -- true for {VDW 2 Cartoon 2}, false for {Cartoon 2 Points 2}). The two-pass walk (simple tiers in GAME_REPS order, then residue tiers in GAME_REPS order) degrades to exactly the plan's behavior for the pinned smoke and is correct for every combination. Root fact: write_combined_pdb emits simple records before residue records (17.2-04 contract).
- **Supply-0 residue tiers degrade, not abort.** 1k8p is DNA (no protein CA anchors); since 17.2-03 the 2-arg randomize can draw a residue tier there. Pre-17.2-09 the defensive skip degraded the round; the naive routing would have turned that into a hard start_game failure (product regression). The dispatch loop now catches the generator error -> vmdcon warn -> 0 records (the cap-at-supply contract's 0-supply edge).
- **Prohibition comment phrased "NEVER call ssrecalc"** (not the literal "mol ssrecalc") so the plan's own verify gate (`grep -c "mol ssrecalc" -> 0`) stays satisfiable while the prohibition is documented at the branch.
- **Smoke double-find check ordered before the win pick.** The plan's step list put the already-found check after the win; post-win the state gate (16-11 precedent) no-ops every pick, so the guard's "Already found!" can only be proven while playing. All plan assertions preserved, order adjusted.
