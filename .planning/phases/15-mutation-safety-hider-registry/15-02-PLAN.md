    3. `make_placeholder_hiders {molid count}` -> list of `{name x y z}` records (research lines 94-107). Center via the NESTED-list-safe form (Pitfall 5: `molinfo $m get center` is `{{x y z}}`, NOT flat; `molinfo $m get {center x}` does NOT exist). Wrap molinfo in catch (bad molid -> center {0 0 0}). Names `G01`..`GNN` via `format "G%02d" [expr {$i+1}]`. Coords = center + deterministic jitter (e.g. `+0.5*$i` on x, `+0.3*$i` on y, `+0.2*$i` on z) so hiders aren't coincident. This proc READS coords only — it does NOT write or load. Pure data prep.

    4. `_hider_record {serial name x y z}` -> 78-char ATOM string (research lines 116-121). CRITICAL: beta is `%6.1f` -> `-999.0` (6 cols, NO overflow — `%6.2f` -> `-999.00` overflows the 6-col beta field and corrupts segid in the PDB; Pitfall 1, probe2b.log). Use EXACTLY this format string (probe-verified):
       ```tcl
       return [format "ATOM  %5d %4s%1s%-3s %1s%4d%1s   %8.3f%8.3f%8.3f%6.2f%6.1f      %-4s%2s" \
           $serial $name " " $HID_RESNAME $HID_CHAIN $HID_RESSEQ " " $x $y $z $HID_OCC $HID_BETA $HID_SEGID $HID_ELEMENT]
       ```

    5. `write_combined_pdb {molid hider_records out_path}` -> orig_n (research lines 122-140). Steps: (a) `set all [atomselect $molid "all"]; $all writepdb $out_path; set orig_n [$all num]; $all delete` (writepdb preserves beta/segid/occ but NOT user — Pitfall 7; irrelevant here). (b) Read file, drop lines where `[string trim $l] eq "END"` or `$l eq ""` (writepdb emits 0 TER + 1 END for 1k8p — no TER handling). (c) Append one hider ATOM per record via `_hider_record`, serial = `orig_n + 1 + i`. (d) `puts $fh "END"; close`. Return `$orig_n`. `out_path` MUST be Windows-visible (caller controls it; for the smoke use a [pwd]-relative path, for game.tcl mutate computes `$env(TEMP)`).

    6. `tag_sentinels {molid}` -> index list (research lines 145-156). Select `resname $HID_RESNAME` (reliably parsed from PDB cols 18-20; A2/A5), then `$sel set beta $HID_BETA; $sel set segid $HID_SEGID` IN-PLACE (rescues any PDB column misalignment — Pitfall 2, proven P5/P6). Per-atom `user` = ordinal (in-session id; LOST on writepdb — Pitfall 7 — but set anyway for the round; the .bcm reconciles later). Return `[$sel get index]`. ALWAYS `$sel delete` (Pitfall 3 — atomselect leaks; a dangling selection on a deleted molecule returns STALE data silently).

    7. `fetch_hider_indices {molid}` -> index list (research lines 162-169). The DI fn. Canonical selector `resname $HID_RESNAME and beta < 0` (NEVER `beta < 0` alone — over-matches any negative-beta real atom, probe.log:699). `[$sel get index]; $sel delete; return $idxs`.

    8. `mutate {molid hider_records}` -> new game molid (research lines 174-181, ADAPTED to the brief's 2-arg signature — compute the temp path internally):
       ```tcl
       proc ::biochemeleon::mutation::mutate {molid hider_records} {
           # Temp path: $env(TEMP) is already a C:/ Windows path (no to_vmd_path needed);
           # fall back to [pwd] (VMD cwd is C:/ under -dispdev text). Fixed name is fine
           # for Phase 15 (single game; writepdb overwrites on restart -- no `rm` needed).
           if {[info exists ::env(TEMP)] && $::env(TEMP) ne ""} {
               set out [file join $::env(TEMP) biochemeleon_game.pdb]
           } else {
               set out [file join [pwd] biochemeleon_game.pdb]
           }
           write_combined_pdb $molid $hider_records $out
           mol delete $molid
           set new_m [mol new $out type pdb waitfor all]
           tag_sentinels $new_m
           return $new_m
       }
       ```
       mutate owns the FORWARD reload: write combined PDB -> `mol delete` ORIGINAL -> `mol new` combined (NEW molid, monotonic > old — Pitfall 4) -> tag sentinels. NO `cleanup` proc in mutation.tcl (the restore-reload is backup::restore).
