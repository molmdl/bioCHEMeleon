<feature>
  <name>Pure sphere-position sampler</name>
  <files>vmd/lib/generators.tcl, vmd/tests/test_generators.test</files>
  <behavior>
    `sphere_positions {minmax n {seed {}}}` where minmax = `{{xmin ymin zmin} {xmax ymax zmax}}`:
    - returns a list of `n` `{x y z}` triples; every x in [xmin,xmax], y in [ymin,ymax], z in [zmin,zmax] (inclusive bounds)
    - count == n for any n >= 0
    - same seed -> identical list (determinism); different seed -> (with overwhelming probability) different list
    - n=0 -> empty list; n=1 -> single point
    - degenerate box (min == max on any/all axes) -> n points, all equal to the degenerate coordinate, NO division-by-zero/error
    - seed == "" -> uses the global PRNG stream without reseeding
  </behavior>
  <implementation>
    Port research §3.2 verbatim: namespace `::biochemeleon::generators`, `namespace export sphere_positions`, one proc. `lassign $minmax lo hi` then per-axis lassign, `for` loop with `lappend pts [list [expr {$xmin + rand() * ($xmax - $xmin)}] ...]`. Seed guard at top. Header comment: file purpose, purity statement, the minmax shape contract, the global-PRNG/seed rule.
  </implementation>
</feature>
