1. `set base [molinfo $molid get numreps]`

(Use braces for the literal selection strings. NO showrep calls anywhere.)

1. `set sel [atomselect $molid "index $idx"]`; `$sel set user2 1`; `$sel delete`
2. Re-issue BOTH modselects with the UNCHANGED strings (hidden rep then found rep) — mandatory re-evaluation re-assert. Guard: if hidden_rep/found_rep are -1 or out of range (`>= [molinfo $molid get numreps]`), error with a clear message ("hider reps not added — call add_hider_reps first").
