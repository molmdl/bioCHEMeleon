Key facts (do NOT re-derive — all PROBE-VERIFIED in tmp/p21probe/):
- **Exact blocking call shape (probeE.tcl, verified end-to-end):**
```tcl
exec curl -sS -L --connect-timeout 15 --max-time 120 -A bioCHEMeleon/2.0 -o $outfile \
     -w {%{http_code} %{size_download}} $url
```
  Returns the `-w` string `"200 7524042"` on stdout; with `-sS` human-readable error text lands in the Tcl error message; `::errorCode` = `CHILDSTATUS <pid> <exit>` (6=DNS 7=conn 22=http(-f-less 404s still exit 0 with -w code) 28=timeout) or `POSIX ENOENT` if curl.exe is absent.
- **UA string `bioCHEMeleon/2.0`** — probes verified it works on all three hosts (RCSB, MemProtMD, SASBDB); v1 precedent set a custom UA because SASBDB may block bare default UAs. [PENDING-APPROVAL at the 21-10 checkpoint — one-line constant if changed.]
- **Integrity gate (RQ5):** parse `-w` -> code must be `200`; `size_download >= min_bytes` (caller passes per-source minimum); first line of the downloaded file must match `^(HEADER|TITLE|ATOM|HETATM|CRYST1|REMARK|COMPND|EXPDTA|SEQRES)` — probe-verified real first lines: MemProtMD `TITLE Gromacs...`, SASBDB `TITLE SWISS-MODEL SERVER`, RCSB `HEADER ...`. Prefer `>= threshold + first-line` over exact-size checks (server-side sizes may drift).
- **Error taxonomy -> user messages (mechanics research matrix):**
  - ENOENT: "This demo needs curl.exe (ships with Windows 10 1803+). Demo can't be fetched on this system."
  - exit 6: "Could not reach <host> — check your internet connection."
  - exit 7: "Could not connect to <host> — the source may be down."
  - exit 22: "HTTP error from <host> — the demo entry appears to have been withdrawn."
  - exit 28: "Timed out fetching the demo (large file) — try again."
  - code != 200 (from -w): "HTTP <code> from <host> — the demo entry appears to have been withdrawn."
  - default: pass the raw message through (it already carries `curl: (n) ...` text).
  Extract `<host>` from the URL with a simple regexp (`https?://([^/]+)/`).
- **Purity contract:** NO `mol`/`atomselect`/`tk` commands in fetch.tcl (it sits beside setup_state in the pure-ish tier; demos.tcl sources it in 21-05). Standalone: sources NOTHING. Namespace `::biochemeleon::fetch`; `variable CURL_UA bioCHEMeleon/2.0` + timeout constants at namespace scope.
- Tcl 8.5: brace ALL expr; catch + errorCode for classification; one `variable` per line.

Procs (exact signatures):
1. `curl_argv {url outfile}` -> the exact list `{curl -sS -L --connect-timeout 15 --max-time 120 -A bioCHEMeleon/2.0 -o <outfile> -w {%{http_code} %{size_download}} <url>}`. Note `-w`'s argument is the literal braces string (its inner braces are curl syntax — test asserts the list element equals `%{http_code} %{size_download}`).
2. `parse_curl_w {wout}` -> {code bytes} as integers. Input is the `-w` output string (e.g. "200 7524042"). Split on whitespace, lassign, both must be pure integers (`string is integer -strict`) -> else `error "fetch::parse_curl_w: malformed curl -w output: <wout>"`.
3. `classify_curl_error {msg ecode {url {}}}` -> user-message string per the taxonomy above (errorCode is the raw ::errorCode list: `POSIX ENOENT {...}` or `CHILDSTATUS <pid> <exit>`); unknown classes -> return $msg verbatim. Host extracted from url when non-empty; when url is empty the messages omit the host phrase gracefully.
4. `first_line_ok {filepath}` -> 1/0. Reads the first line (`open`/`gets`/`close` with catch on missing file -> 0); first non-empty line must match PDB_FIRST_LINE_RE. Handles CRLF (`string trimright \r`).
5. `curl_get {url outfile min_bytes}` -> downloaded byte count (integer). Implementation: `if {[catch {exec {*}[curl_argv $url $outfile]} wout]} { error [classify_curl_error $wout $::errorCode $url] "" $::errorCode }`; lassign [parse_curl_w $wout] code bytes; code ne 200 -> error (withdrawn message); bytes < min_bytes -> error "Download incomplete (got <bytes> bytes) — retry."; first_line_ok fails -> error "Downloaded file is not a PDB stream — retry." (caller deletes the bad file). Deterministic parts tested; the exec path is exercised by Task 3.
