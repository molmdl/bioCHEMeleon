<objective>
Write and run a headless research spike (`smoke/altconf_spike.py`) that determines
whether the **alt-conf segment replication** approach can work for cartoon/ribbon
hiders in PyMOL 2.5.0. The 05-05 human-verify found the terminal-extension approach
renders as DISCONNECTED on 1ubq. The roadmap's alternative is "replicating a segment
(loop) as an alternate position using C-alpha geometry" — this spike tests whether
that approach is viable before committing implementation effort in plan 05-08.

Purpose: The alt-conf approach has NEVER been tested at runtime. The existing research
(05-RESEARCH.md §3 Q9) deferred it as "meaningfully harder" with LOW confidence. The
key unknowns are: (1) can `cmd.create(obj, sele, 1, 1)` duplicate atoms within the
SAME object, (2) does the cartoon renderer show alt-conf (alt='B') atoms, (3) can
`cmd.alter_state` displace the copies for visibility, (4) does cleanup by `segi GAME`
restore the original. This spike answers all four headlessly.

Output: `smoke/altconf_spike.py` (~100 lines, pure `pymol.cmd.*` — NO Qt) + appended
§12 to `05-RESEARCH.md` with findings + implementation recommendation for 05-08.
</objective>

    **--- 2. Can cmd.create duplicate atoms within the SAME object? ---**

    Print `diag: new_ids count = %d` (expect ~30 for 3 residues × ~10 atoms).

    **--- 3. Do duplicates have the same chain/resi/name as originals? ---**

    Read new CA props: `new_props = []; cmd.iterate("id " + "+".join(str(i) for i in new_ids) + " and name CA", "stored.append((chain, resv, name))", space={'stored': new_props})`.

    if clickable_id: `cmd.alter("%s and id %d" % (obj, clickable_id), "b=-999.0", space={})`.

    **--- 5. Does cartoon render the alt-conf atoms? (KEY QUESTION) ---**
    `cmd.show('cartoon', _id_sele(new_ids))` (viewing.py:491 — newly-created atoms
    do NOT inherit shown reps; must explicitly show).

    `check("cartoon: alt-conf GAME CA in rep cartoon (default settings)", game_cartoon_ca > 0)`.
    Print `diag: game_cartoon_ca = %d`.

    `game_cartoon_ca_all = cmd.count_atoms("%s and segi GAME and name CA and rep cartoon" % obj)`.

    Print `diag: game_cartoon_ca_all = %d`. Note whether all_states changed the
    result (if both are >0, all_states is NOT needed; if only the second is >0,
    all_states IS required — document this critical finding in the diag output).
    `cmd.set("all_states", "off")` (reset).

    **--- 7. Are alt-conf atoms classified as polymer? ---**
    `game_polymer = cmd.count_atoms("%s and segi GAME and polymer" % obj)`.
    `check("cartoon: alt-conf GAME atoms in polymer", game_polymer > 0)`.
    Print `diag: game_polymer = %d` (the polymer selector is C-side,
    connectivity-based — cmd.py:363. If 0, the duplicates are NOT polymer and the

    `check("ribbon: alt-conf GAME CA in rep ribbon", game_ribbon_ca > 0)`.
    Print `diag: game_ribbon_ca = %d`.

    **--- 9. Can cmd.alter_state displace alt-conf atoms for visibility? ---**

    Read displaced coords: `new_coords = []; cmd.iterate_state(1, _id_sele(new_ids) + " and name CA", "stored.append((x, y, z))", space={'stored': new_coords})`.
    `check("displace: alter_state moved alt-conf atoms", len(orig_coords) > 0 and len(new_coords) > 0 and abs(new_coords[0][0] - orig_coords[0][0] - 2.0) < 0.01)`.
    Print `diag: orig_coords[0]=%r new_coords[0]=%r`.
