<objective>
Implement the **alt-conf segment replication** approach for cartoon/ribbon hiders,
REPLACING the terminal-extension approach that rendered as disconnected on 1ubq.
Based on the 05-06 research spike findings, this plan:
1. Rewrites `insert_cartoon_hider` in `mutation.py` to duplicate a mid-chain segment
   as an alt-conf (alt='B') copy, displaced slightly for visibility, rendering as a
   CONNECTED part of the cartoon trace.
2. Adds `pick_segments` to `generators.py` (pure, TDD) — picks mid-chain segments
   (not terminals), multiple per chain.
3. Updates `__init__.py` `_on_start` to use `pick_segments` + the new payload format,
   and removes the `free_nterminal_valence` call (not needed for alt-conf).
4. Adds ribbon support (the `rep` parameter is passed through and `cmd.show(rep, ...)`
   shows the REQUESTED rep, not hardcoded cartoon).
5. Updates the smoke test to verify the alt-conf path.
6. Ends with a human-verify checkpoint confirming the visual blend on 1ubq.

Purpose: The 05-05 human-verify found the terminal-extension cartoon hider renders
as DISCONNECTED on 1ubq (fundamental limitation). The roadmap success criterion 2
says "replicating a segment (loop) as an alternate position using C-alpha geometry"
— this plan implements that approach. It also fixes the ribbon error (currently
ribbon is selected but cartoon is hardcoded in the show call).

Output: `mutation.py` (alt-conf insert_cartoon_hider + rep param),
`generators.py` (pick_segments + unit tests), `__init__.py` (updated dispatch),
`smoke/phase5_smoke.py` (alt-conf + ribbon tests), human-verify checkpoint.
</objective>

       `cmd.alter_state(1, _id_sele(new_ids), "x=x+dx; y=y+dy; z=z+dz", space={'dx': dx, 'dy': dy, 'dz': dz})`
