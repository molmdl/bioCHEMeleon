    The full Phase 5 mixed-rep hider generation: `__init__._on_start` now reads
    `state["per_rep"]` and builds mixed-rep `hider_specs` (spheres via
    `generate_sphere_positions`, lines/sticks via
    `generate_line_stick_offsets` + sampled neighbor ids, cartoon via
    `pick_terminal_residues`). `GameController.start` dispatches each spec via
    `mutation.insert_hider_for_rep`, which routes to `insert_hider` (spheres +
    show by id), `insert_line_stick_hider` (pseudoatom + `cmd.bond` + color/elem
    blend + show sticks/lines by id), or `insert_cartoon_hider`
    (`cmd.attach_amino_acid` 'gly' at C-terminus + sentinel + color/ss blend +
    show cartoon on the new residue). All hiders keep the `segi='GAME'`+`b=-999`
    sentinel and copy a neighbor's color/elem so the default rendering blends
    (option c — the sentinel is UNCHANGED so Phase 3 cleanup/read paths work
    untouched). The headless smoke (plan 05-04) confirmed the mechanism: atoms
    insert, reps show, GAME atoms are in polymer, sentinel set, color matches
    neighbor, cleanup restores. This checkpoint confirms the VISUAL BLEND +
    click-to-find + cleanup in a real GUI session.
  </what-built>
  <how-to-verify>
    Run the plugin in a real Windows PyMOL session (NOT WSL — Qt/GUI needs a
    real display):

    **Setup:**
    1. Launch PyMOL via `setenv.bat` then `pymol` (Windows conda env).
    2. Load a polymer molecule: `fetch 1ubq` (ubiquitin — a single-chain protein
       with a clear cartoon). Confirm it renders. Show cartoon
       (`as cartoon, 1ubq` or the cartoon S button).
    3. Open the bioCHEMeleon plugin from the Plugins menu. Go to the Setup tab.

    **Test A — Cartoon hider blend (success criterion 2):**
    4. In Setup: select the loaded object (1ubq), set per_rep to cartoon=1 (tick
       the cartoon row, set count to 1), leave other reps at 0. Set total hider
       count to 1. Click Start.
    5. **Criterion 2a**: Confirm an extra cartoon tube segment appears at the
       C-terminus of the chain (a small loop extension). It should BLEND with
       the existing cartoon — same color, same tube style, not a glaringly
       different residue. (If it's a wildly different color or clearly sticks
       out, the color-blend or ss choice needs adjustment — report the symptom.)
    6. **Criterion 2b**: Click the extra segment (the new Cα). Confirm it
       recolors green and the remaining count drops to 0. Confirm the win
       message appears.
    7. After winning, dismiss the dialog. Confirm cleanup removed the extra
       residue (the cartoon looks identical to pre-game — no extra loop at the
       terminus).

    **Test B — Line/stick hider blend (success criterion 1):**
    8. Reload 1ubq (or start a new game). Show sticks (`as sticks, 1ubq`).
    9. In Setup: set per_rep to sticks=2 (tick sticks, count 2), other reps 0.
       Total hider count 2. Click Start.
    10. **Criterion 1a**: Confirm 2 extra short bonds appear among the real
        bonds, near real atoms. They should BLEND — same color as the nearby
        atoms, short bonds that look like real bonds (not floating lone atoms).
        (If they're a different color or clearly disconnected, report.)
    11. **Criterion 1b**: Click each extra bond's atom. Confirm each recolors
        green, remaining drops, and the win message appears when both found.
    12. After winning, confirm cleanup removed the extra atoms (the stick model
        looks identical to pre-game).

    **Test C — Mixed-rep game (success criterion 3):**
    13. Reload 1ubq. Show all reps: `show cartoon, 1ubq; show sticks, 1ubq;
        show spheres, 1ubq` (or use the S buttons — cartoon + sticks + spheres
        all visible).
    14. In Setup: set per_rep to spheres=1, sticks=1, cartoon=1. Total hider
        count 3. Click Start.
    15. **Criterion 3a**: Confirm 3 hiders appear — 1 sphere (among real atoms),
        1 stick (extra short bond), 1 cartoon (extra loop at terminus). Each
        should blend with its respective rep.
    16. **Criterion 3b**: The Game tab should show remaining=3 (and per-rep
        counts if easy difficulty: spheres 1, sticks 1, cartoon 1).
    17. **Criterion 3c**: Click each hider (in each rep). Confirm each
        recolors green, remaining drops, and the win message appears when all 3
        found.
    18. After winning, confirm cleanup restored the structure (no extra atoms,
        bonds, or residues — the model looks identical to pre-game).

    **Test D — spectrum b limitation (documented, NOT a failure):**
    19. (Optional) Start a game with any rep. In the PyMOL command line, type
        `spectrum b, rainbow, 1ubq`. Confirm the hider(s) show up at the
        extreme (b=-999 is far below the real b-factor range). This is the
        KNOWN limitation / "debug cheat" documented in 05-RESEARCH.md §4 Q15 —
        the sentinel b=-999 is revealed by spectrum b. This is ACCEPTED (not a
        bug); the sentinel is kept intact so Phase 3 cleanup works. Just
        confirm it behaves as documented (no crash, hiders visible at the
        extreme).

    Report PASS/FAIL per test (A: 2a/2b, B: 1a/1b, C: 3a/3b/3c) + the cleanup
    checks + the optional spectrum-b observation. If any criterion fails,
    describe the symptom precisely (what you clicked, what you expected, what
    happened — e.g., "cartoon hider was red, not blending" or "stick hider
    floating in space, not bonded") so the next iteration can target it.
