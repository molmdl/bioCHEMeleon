<objective>
Wire the mixed-rep hider generation: `__init__._on_start` builds mixed-rep
`hider_specs` from `state["per_rep"]` (calling the pure generators from plan
05-01 + the cmd.iterate data fetching), and `GameController.start` dispatches
each spec via `mutation.insert_hider_for_rep` (plan 05-02) instead of the old
direct `insert_hider`. This is the ONE plan that touches both `game.py`
(consumer) and `__init__.py` (producer) because the `hider_specs` shape is a
SHARED contract between them — coordinating them in one plan prevents contract
drift.

Purpose: This delivers success criterion 3 (mixed reps all tracked in the
registry). The `hider_specs` shape changes from `[(pos, rep)]` (Phase 4, all
spheres) to `[(payload, rep)]` where `payload` is rep-specific (`[x,y,z]` for
spheres, `(offset, neighbor_id)` for lines/sticks,
`(chain, terminus_resi, is_c_terminus)` for cartoon/ribbon). The existing
`for (payload, rep) in hider_specs` unpacking in `game.py.start` stays
backward-compatible (sphere `pos` IS the payload). The dispatcher handles the
variant.

Output: `biochemeleon/game.py` (~137 → ~145 lines, loop body changed) +
`biochemeleon/__init__.py` (~129 → ~185 lines, `_on_start` extended).
</objective>

    ```python
    # 2. Build mixed-rep hider_specs
    extent = cmd.get_extent(target_obj)
    hider_specs = []
    # Pre-fetch the data the pure generators need (cmd-coupled, here in _on_start):
    # For line/stick: sample neighbor atom ids
    neighbor_ids = []
    cmd.iterate("%s and not segi GAME" % target_obj,
                "stored.append(ID)", space={'stored': neighbor_ids})
    # For cartoon: find terminal C-alpha per chain
    cas_list = []

                "stored.append((chain, int(resi), ID))", space={'stored': cas_list})
    cas_by_chain = {}

        cas_by_chain.setdefault(chain, []).append((resi, ca_id))
    _rng = _random.Random()  # for neighbor sampling (non-deterministic is fine for gameplay)
    for rep, count in per_rep.items():
        if rep == 'spheres':
            positions = generators.generate_sphere_positions(extent, count)
            hider_specs += [(p, 'spheres') for p in positions]
        elif rep in ('lines', 'sticks'):
            offsets = generators.generate_line_stick_offsets(count)
            n_avail = min(count, len(neighbor_ids))
            chosen = _rng.sample(neighbor_ids, n_avail) if neighbor_ids else []
            for off, nbr_id in zip(offsets, chosen):
                hider_specs.append(((off, nbr_id), rep))
        elif rep in ('cartoon', 'ribbon'):
            # Cap: one terminal extension per chain (attaching many to one
            # terminus chains them -- 05-RESEARCH.md Open Risk 5). Limit to
            # available chains.
            terminals = generators.pick_terminal_residues(cas_by_chain, max_chains=count)
            for term in terminals:
                hider_specs.append((term, rep))  # term = (chain, terminus_resi, is_c_terminus)
    # Fallback: if per_rep is empty (random mode unset), default to spheres
    # (Phase 4 behavior) using the total hider_count.
    if not hider_specs:
        count = int(state.get("hider_count", 0))
        positions = generators.generate_sphere_positions(extent, count)
        hider_specs = [(pos, "spheres") for pos in positions]
    ```
