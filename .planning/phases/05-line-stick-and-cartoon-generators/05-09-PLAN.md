<objective>
Fix gap #3 from the 05-05 partial approval: when a user selects `ribbon` in
`per_rep` and clicks Start, the game inserts cartoon-geometry hiders but shows
them in the **cartoon** representation, not ribbon. The root cause is a single
hardcoded `'cartoon'` literal in `insert_cartoon_hider`'s `cmd.show` call
(`biochemeleon/mutation.py` line 478). The function never receives `rep`.

Purpose: Close the last mechanically-fixable Phase 5 gap (ribbon support) so
the `ribbon` rep becomes playable. This is explicitly scoped to ribbon ONLY —
alt-conf segment replication (gap #1, disconnected cartoon on 1ubq) is DEFERRED
to Phase 11, and the line/stick IndexError (gap #2) was already fixed via 05-07.
Per the gap brief, this is a 1-source-file fix (3 small changes in
`mutation.py`) + a smoke extension: add a `rep='cartoon'` parameter to
`insert_cartoon_hider`, parameterize the `cmd.show` call to use `rep`, and
forward `rep=rep` from the `insert_hider_for_rep` dispatcher. NO `__init__.py`
change is needed — the `(chain, terminus_resi, is_c_terminus)` payload already
travels with the rep via `hider_specs.append((term, rep))` and `game.start`'s
loop passes `rep` to `insert_hider_for_rep`, which now forwards it.

Why this is low-risk (headless-verifiable, no GUI-vs-headless trap): it is just
a `cmd.show` call — no `cmd.create`, no state manipulation, no coordinate
changes. The `auto_zoom`/multi-state/coord-corruption class of bugs that killed
the alt-conf attempt (05-06/05-08, reverted) CANNOT occur here. Headless smoke
CAN verify the fix directly: `count_atoms("obj and segi GAME and rep ribbon") > 0`
AND `count_atoms("obj and segi GAME and rep cartoon") == 0` after inserting a
ribbon hider. The reverted 05-08 already proved `cmd.show(rep, ...)` works (it
was in the alt-conf version that passed headless smoke).

Output: `biochemeleon/mutation.py` (3 small changes — signature, show call,
dispatcher), `smoke/phase5_smoke.py` (new section 5c — ribbon rep check). This
mirrors the 05-07 gap-closure precedent (minimal 1-file fix + smoke section +
headless smoke as the gate, autonomous, no human-verify checkpoint).
</objective>
