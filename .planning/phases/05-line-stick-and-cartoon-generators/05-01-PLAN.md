    drawn uniform-random in `[-1.0, 1.0]` Å. A `seed` makes output deterministic.
    Used by `__init__._on_start` to place line/stick hiders near real neighbors
    (offset added to a neighbor's coords — 05-RESEARCH.md §2 Q3: "0.5-1.0 Å so

    Cases:
      - generate_line_stick_offsets(5, seed=42) -> len==5; every component in [-1.0, 1.0]
      - same seed -> identical list (two calls with seed=42 compare equal)
      - different seeds -> different lists (seed=1 vs seed=2 differ)
      - n=0 -> [] (no error)
      - n=1 -> len==1
      - each offset is a 3-element list of floats (not tuple, not nested)

    **pick_terminal_residues(cas_by_chain, max_chains=None):**
    `cas_by_chain` is `{chain: [(resi, ca_id), ...]}` (produced by the caller's
    `cmd.iterate` — 05-RESEARCH.md §3 Q8 Step 1). Returns a list of
    `(chain, terminal_resi, is_c_terminus)` tuples, one per chain, sorted
    longest-chain-first (most Cα entries), each using the C-terminus (max resi,
    `is_c_terminus=True`). Capped at `max_chains` if not None. Returns `[]` for
    an empty dict. Used by `__init__._on_start` to build cartoon hider payloads
    (one terminal extension per chain — 05-RESEARCH.md §7 Open Risk 5: attaching
    many to one terminus chains them, so cap at one per chain).

    Cases:
      - pick_terminal_residues({}) -> []
      - pick_terminal_residues({'A': [(1,'id1'),(2,'id2'),(76,'id76')]}) ->
        [('A', 76, True)]  (single chain, C-terminus = max resi)
      - pick_terminal_residues({'A': [(1,1),(76,76)], 'B': [(1,1),(50,50)]}) ->
        [('A', 76, True), ('B', 50, True)]  (chain A longer, listed first)
      - pick_terminal_residues({'A': [...], 'B': [...]}, max_chains=1) ->
        [('A', ..., True)]  (only the longest chain)
      - is_c_terminus is always True (MVP uses C-terminus only; N-terminus is a
        future option — 05-RESEARCH.md §3 Q8)
  </behavior>
  <implementation>
    Extend the existing `biochemeleon/generators.py` (which already has
    `generate_sphere_positions` from Phase 4). Add two functions AFTER the
    existing one. Keep the module pure: `import random` only, NO `from pymol`,
    NO `numpy`.

    ```python
    def generate_line_stick_offsets(n, seed=None):
        """Generate n small [dx,dy,dz] offset vectors for line/stick hiders.

        Each component is drawn uniform-random in [-1.0, 1.0] Angstrom so the
        hider sits near a real neighbor (short bond, blends with real bonds).
        seed: int for deterministic output (tests). Returns: list of [dx,dy,dz]
        lists (empty when n <= 0).
        """
        rng = random.Random(seed)
        return [[rng.uniform(-1.0, 1.0) for _ in range(3)] for _ in range(n)]


    def pick_terminal_residues(cas_by_chain, max_chains=None):
        """Pick terminal residues for cartoon hiders (extend-at-terminal, MVP).

        cas_by_chain: {chain: [(resi, ca_id), ...]} from the caller's
        cmd.iterate over polymer C-alpha atoms. Returns a list of
        (chain, terminal_resi, is_c_terminus) tuples, one per chain, longest
        chain first, each at the C-terminus (max resi, is_c_terminus=True).
        Capped at max_chains if not None. Returns [] for an empty dict.

        MVP caps cartoon hiders at one per chain (attaching many to one
        terminus chains them -- 05-RESEARCH.md Open Risk 5). N-terminus is a
        future option; MVP uses C-terminus only.
        """
        if not cas_by_chain:
            return []
        chains = sorted(cas_by_chain.keys(),
                        key=lambda c: len(cas_by_chain[c]), reverse=True)
        if max_chains is not None:
            chains = chains[:max_chains]
        out = []
        for ch in chains:
            resis = [r[0] for r in cas_by_chain[ch]]
            out.append((ch, max(resis), True))  # C-terminus (max resi)
        return out
    ```
    Update the module docstring to mention the two new functions. Keep the
    "NO from pymol, NO from pymol.Qt" purity statement.
  </implementation>
