       ```python
       logs = []; rems = []; wins = []; counts = []
       gc.set_callbacks(on_log=lambda m: logs.append(m),
                        on_remaining_changed=lambda r: rems.append(r),
                        on_win=lambda e: wins.append(e),
                        on_counts_changed=lambda h, r: counts.append((h, r)))
       gc._start_time = 1234.0
       ```

    6. HINT test — call `gc.hint()` and verify the neighbor coloring:
       ```python
       gc.hint()
       check("hint: _hint_count == 1", gc._hint_count == 1)
       check("hint: on_counts_changed fired", len(counts) >= 1 and counts[-1] == (1, 0))
       # Hint colors neighbor atoms orange (not the hider, not GAME atoms)
       orange_count = cmd.count_atoms("%s and color orange" % obj)
       check("hint: orange atoms exist (neighbors colored)", orange_count > 0)
       # CRITICAL: NO GAME atoms colored by hint (around excludes the hider
       # atom; not segi GAME excludes support atoms + other hiders)
       orange_game = cmd.count_atoms("%s and color orange and segi GAME" % obj)
       check("hint: NO GAME atoms colored orange", orange_game == 0)
       # All hiders still hidden (hint does NOT mark_found)
       all_hidden = all(r.status == registry.HIDER_STATUS_HIDDEN
                        for r in gc.registry.all())
       check("hint: all hiders still hidden (no mark_found)", all_hidden)
       check("hint: log message fired", len(logs) >= 1)
       ```

    7. REVEAL-ONE test — call `gc.reveal_one()` and verify:
       ```python
       before_found = sum(1 for r in gc.registry.all()
                          if r.status == registry.HIDER_STATUS_FOUND)
       gc.reveal_one()
       after_found = sum(1 for r in gc.registry.all()
                         if r.status == registry.HIDER_STATUS_FOUND)
       check("reveal_one: exactly 1 more found",
             after_found == before_found + 1)

       ```

       check("reveal_all: _reveal_count == 1 + hidden_before",

       all_hiders_green = all(
           # Read color for each hider id

               # cmd.iterate exposes color as an int index, not a name.
               # Just assert the hider atom's color CHANGED (is not the

             green_game_all >= len(gc.registry.all()))

  <what-built>
    The full Phase 6 hint/reveal mechanics: three buttons in the Game status
    tab (Hint, Reveal one, Reveal all) + a reveal counter label. The Hint
    button (gui_game.py) calls GameController.hint() (game.py) which colors
    the residues around a random hidden hider orange using the PyMOL
    `(byres (obj and id N around 5)) and not segi GAME` selection. The
    Reveal-one button shows a QMessageBox.question Yes/No confirm dialog;
    on Yes, GameController.reveal_one() marks one random hidden hider found
    + green (via the shared _mark_found helper) and increments the reveal
    counter. The Reveal-all button shows a confirm dialog; on Yes,
    Gamecontroller.reveal_all() marks all remaining hiders found + green,
    increments the counter by N, and fires win(). The reveal counter label
    ("Reveals: N") updates via the on_counts_changed callback. All three
    buttons guard when no game is active or all hiders are found.
  </what-built>
