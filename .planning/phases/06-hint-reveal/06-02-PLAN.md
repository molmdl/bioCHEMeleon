       ```python
       def _confirm(self, title, text):
           """Yes/No confirm. Uses top-level window as parent so the dialog
           appears above the PyMOL OpenGL window (same fix as _finish_win)."""
           btns = QtWidgets.QMessageBox.Yes | QtWidgets.QMessageBox.No
           return QtWidgets.QMessageBox.question(
               self.window(), title, text, btns) == QtWidgets.QMessageBox.Yes
       ```

    2. `_on_counts_changed(self, hint_count, reveal_count)` — callback slot
       that updates the reveal counter label. `hint_count` is stored for

       ```python
           self._reveal_label.setText("Reveals: %d" % reveal_count)
       ```

    3. `_on_hint_clicked(self)` — Hint button slot. Hint is help (NOT give-up),
       so NO confirm dialog. Guards: early-return when controller is None,
       not started, or remaining==0. Place after `_on_counts_changed`:
       ```python
       def _on_hint_clicked(self):
           if self._controller is None or not self._controller._started:
               return
           if self._controller._remaining() == 0:
               return
           self._controller.hint()
       ```

    4. `_on_reveal_one_clicked(self)` — Reveal-one button slot. Shows confirm
       dialog BEFORE calling the controller. Place after `_on_hint_clicked`:
       ```python
       def _on_reveal_one_clicked(self):
           if self._controller is None or not self._controller._started:
               return
           if self._controller._remaining() == 0:
               return
           if not self._confirm("Reveal one hider?",
                   "Give up on one random hider? This counts as a reveal use."):
               return
           self._controller.reveal_one()
       ```

    5. `_on_reveal_all_clicked(self)` — Reveal-all button slot. Shows confirm
       dialog BEFORE calling the controller. Place after `_on_reveal_one_clicked`:
       ```python
       def _on_reveal_all_clicked(self):
           if self._controller is None or not self._controller._started:
               return
           if self._controller._remaining() == 0:
               return
           if not self._confirm("Reveal all hiders?",
                   "Give up and reveal ALL remaining hiders? This ends the game."):
               return
           self._controller.reveal_all()
       ```

    6. Wire the button click signals in `__init__` — add these 3 lines
       AFTER the `btn_row` layout lines (Task 1), still inside `__init__`:
