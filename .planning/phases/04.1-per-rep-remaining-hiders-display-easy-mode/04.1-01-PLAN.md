  <behavior>
    A new pure method on `HiderRegistry` that returns `{rep: count}` for every
    rep in `GAME_REPS` (zero-filled), counting ONLY hidden records. Testable
    behaviors (each `expect(fn(input)).toBe(output)`):

    - Empty registry: `remaining_by_rep()` == `{'lines':0,'sticks':0,'spheres':0,'cartoon':0,'ribbon':0}` (all 5 GAME_REPS keys, zero-filled).
    - All 5 keys always present (zero-fill), regardless of which reps are registered.
    - Hidden-only filter: register 3 sphere records (2 hidden, 1 found) → `remaining_by_rep()['spheres'] == 2` (does NOT count the found one).
    - Mixed reps + mixed statuses: register sphere(hidden), stick(found), cartoon(hidden) → `{'lines':0,'sticks':0,'spheres':1,'cartoon':1,'ribbon':0}`; `sum(values()) == 2 == count of hidden records`.
    - Sums to remaining: for any registry state, `sum(remaining_by_rep().values()) == len([r for r in all() if r.status == HIDER_STATUS_HIDDEN])` (this is exactly what `GameController._remaining()` counts — SC3 contract).
    - rep=None skip: a record with `rep=None` (e.g. from `reconstruct_from_sentinels`) is SKIPPED — never counted, never raises KeyError.
    - mark_found decrement: register 2 hidden spheres, `mark_found` one → `remaining_by_rep()['spheres'] == 1` (decremented by 1).
    - Equals counts_by_rep when all hidden: if every record has `status == HIDER_STATUS_HIDDEN`, `remaining_by_rep() == counts_by_rep()`.

    Purity: `remaining_by_rep` uses only `self._records`, `GAME_REPS`,
    `HIDER_STATUS_HIDDEN` — all already in registry.py. NO `from pymol`, NO Qt.
  </behavior>
  <implementation>
    Add `remaining_by_rep` to `HiderRegistry` immediately AFTER `counts_by_rep`
    (registry.py ~line 264), behind a `# ---- Hidden-only per-rep counts (Phase 4.1) ----`
    section comment. Mirror `counts_by_rep` exactly, adding ONE line
    (`if r.status == HIDER_STATUS_HIDDEN:`) around the increment:

    ```python
    def remaining_by_rep(self):
        """Return {rep: count} for HIDDEN records, keyed by GAME_REPS.

        Mirrors counts_by_rep but filters status == HIDER_STATUS_HIDDEN so the
        per-rep counts SUM to the total remaining (GAME-03 / SC3). Skips
        rep=None records (same as counts_by_rep — post-.pse reload ghosts).
        Zero-fills reps with no hidden hiders. Pure (no pymol, no Qt).
        """
        out = {rep: 0 for rep in GAME_REPS}
        for r in self._records.values():
            if r.rep is None:
                continue
            if r.status == HIDER_STATUS_HIDDEN:
                out[r.rep] = out.get(r.rep, 0) + 1
        return out
    ```

    Update the `HiderRegistry` class docstring's API list (the line that
    enumerates `by_rep` / `counts_by_rep` / `mark_found` ...) to also name
    `remaining_by_rep`. Write docstrings in PROSE (avoid literal `from pymol`
    or `cmd.` tokens that trip the Pitfall-1 grep gate — mirrors the
    03-02/06/09/10 docstring precedent).
  </implementation>
