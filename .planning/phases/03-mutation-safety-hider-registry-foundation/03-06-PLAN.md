```python
def fetch_all_hider_ids(object):
    """All hider ids in object (by sentinel segi GAME + b -999). Returns list of (object_name, id) tuples.
    Used by registry.reconstruct_from_sentinels (via DI) and the smoke test id-stability check."""
    out = []
    cmd.iterate(f"{object} and segi GAME and b -999", "stored.append((model, id))",
                space={'stored': out})                            # editing.py:1490
    return out  # list of (object_name, id)
```
CRITICAL points:
- Use `cmd.iterate` with `space={'stored': out}` (NOT `space=None`) — RESEARCH §Q3 confirms `space=None` pollutes the global `pymol.__dict__`; the explicit dict is the hygienic pattern (editor.py:156).
- The selector is `segi GAME and b -999` — the sentinel. `model` and `id` are read-only symbols exposed by iterate (editing.py:1446-1449). `id` is the STABLE integral identifier (NOT `index` — RESEARCH §Q4).
- Returns `(model, id)` tuples (model = object name) so the registry can key by `(object, id)` even in multi-object future scenarios.
