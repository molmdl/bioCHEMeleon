<feature>
  <name>HiderRecord + HiderRegistry core CRUD</name>
  <files>biochemeleon/registry.py, tests/test_registry.py</files>
  <behavior>
    HiderRecord(id, object, rep, status='hidden', pos=None):
      - rejects rep not in GAME_REPS with ValueError
      - .key() returns (object, int(id))
      - .to_dict() returns {'id','object','rep','status'} (+ 'pos' as list only if pos is not None)
      - __slots__ = ('id','object','rep','status','pos')
    HiderRegistry():
      - register(object, id, rep, status='hidden', pos=None) -> HiderRecord; raises KeyError on duplicate (object,id)
      - get(object, id) -> HiderRecord or None
      - all() -> list of HiderRecord (insertion order)
      - remove(object, id) -> bool (True if removed, False if absent)
    Cases:
      - HiderRecord(1, '1ubq', 'spheres') -> key==('1ubq',1), status=='hidden', pos==None
      - HiderRecord(1, '1ubq', 'surface') -> raises ValueError
      - registry.register('1ubq', 1, 'spheres'); registry.get('1ubq', 1) -> rec; registry.all() == [rec]
      - registry.register('1ubq', 1, 'spheres') twice -> second raises KeyError
      - registry.remove('1ubq', 1) -> True; registry.remove('1ubq', 1) -> False (already gone)
  </behavior>
  <implementation>
    Use the code sketch in 03-RESEARCH.md §"Registry Design" (lines 194-237) as the exact blueprint:
    - `from collections import OrderedDict`
    - `from .setup_state import GAME_REPS`
    - `HIDER_STATUS_HIDDEN = 'hidden'`, `HIDER_STATUS_FOUND = 'found'`
    - HiderRecord with __slots__, validation (rep in GAME_REPS), key()=(self.object, self.id), to_dict()
    - HiderRegistry with self._records = OrderedDict(); register checks duplicate key; get/all/remove per sketch
    Module MUST be pure: NO `from pymol import` and NO `from pymol.Qt import`. Imports only stdlib + setup_state.
  </implementation>
</feature>
