```python
def cleanup_hiders(object):
    """Remove all hiders from object by sentinel (segi GAME). Returns count removed.
    Happy-path cleanup: cmd.remove deletes atoms FROM the object (not the object itself).
    Idempotent: returns 0 if no hiders present."""
    before = cmd.count_atoms(f"{object} and segi GAME")           # querying.py:1412
    if before:
        cmd.remove(f"{object} and segi GAME")                     # editing.py:800
    return before
```
CRITICAL points:
- `cmd.remove("obj and segi GAME")` removes atoms FROM the object — it does NOT delete the object (unlike `cmd.delete` which removes the whole object). This is the happy-path cleanup: the original structure stays, only hiders are removed.
- Selector is `segi GAME` ONLY — never `resi`/`chain`/`index` (AGENTS.md: "Cleanup and session reload identify hiders by sentinel ONLY — never by resi/chain/per-object index (unstable across deletions)").
- `before` count is returned so the caller (game.py cleanup) can assert it matches the registry length. If `before == 0`, `cmd.remove` is skipped (idempotent — no error on zero-atom selection).
- `cmd.count_atoms` is cheap (querying.py:1412) — used as the gate to avoid calling remove on an empty selection.
