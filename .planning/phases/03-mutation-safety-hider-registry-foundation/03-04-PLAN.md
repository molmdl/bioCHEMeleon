<feature>
  <name>HiderRegistry queries: by_rep, counts_by_rep, mark_found</name>
  <files>biochemeleon/registry.py, tests/test_registry.py</files>
  <behavior>
    HiderRegistry.by_rep(rep) -> list of HiderRecord where r.rep == rep (insertion order)
    HiderRegistry.counts_by_rep() -> dict {rep: count} for ALL reps in GAME_REPS (zero-filled for reps with no hiders)
    HiderRegistry.mark_found(object, id) -> sets r.status = 'found' for the record at (object, id); raises KeyError if not registered
    Cases:
      - register 3 hiders: ('1ubq', 1, 'spheres'), ('1ubq', 2, 'sticks'), ('1ubq', 3, 'spheres')
      - by_rep('spheres') -> [rec1, rec3] (insertion order)
      - by_rep('cartoon') -> [] (empty list, not None)
      - counts_by_rep() -> {'lines':0, 'sticks':1, 'spheres':2, 'cartoon':0, 'ribbon':0}
      - mark_found('1ubq', 2) -> rec2.status == 'found'; rec1.status == 'hidden' (unaffected)
      - mark_found('1ubq', 999) -> raises KeyError (not registered)
  </behavior>
  <implementation>
    Follow 03-RESEARCH.md §"Registry Design" sketch (lines 207-217):
    - `by_rep(self, rep)`: return `[r for r in self._records.values() if r.rep == rep]`
    - `counts_by_rep(self)`: `out = {r: 0 for r in GAME_REPS}` then `for r in self._records.values(): out[r.rep] = out.get(r.rep, 0) + 1`; return out. Note: zero-fills ALL GAME_REPS (so the Game tab can show "cartoon: 0" even when no cartoon hiders exist).
    - `mark_found(self, object, id)`: `rec = self._records[(object, int(id))]; rec.status = HIDER_STATUS_FOUND` (raises KeyError if absent — that's the desired behavior for "click a non-registered atom" error signaling)
  </implementation>
</feature>
