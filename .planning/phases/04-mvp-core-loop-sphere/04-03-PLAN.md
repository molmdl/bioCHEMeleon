    defaulting each to a no-op lambda when None.

    `win()` = `elapsed = time.time() - self._start_time`; `self._on_win(elapsed)`;
    if `self._wizard`: `self._wizard.deactivate(); self._wizard = None`.
    `_started` STAYS True after win (hiders remain until cleanup(); 04-RESEARCH Q29).

      - on_pick(last hidden hider) with _wizard set (mock) -> _wizard.deactivate

      - set_callbacks(None) -> all three attrs are callable no-ops (calling them

  <implementation>
    Extend the existing `GameController` class (DO NOT change `start`/`cleanup`/
    `abort_on_error`/`reconstruct_registry` — Phase 3 proven). Add `import time`
    at the top. In `__init__` add: `self._start_time = None`, `self._wizard = None`,
    `self._on_log = lambda msg: None`, `self._on_remaining_changed = lambda r: None`,
    `self._on_win = lambda elapsed: None`. Then add methods:

    ```python
    def set_callbacks(self, on_log=None, on_remaining_changed=None, on_win=None):
        self._on_log = on_log or (lambda msg: None)
        self._on_remaining_changed = on_remaining_changed or (lambda r: None)
        self._on_win = on_win or (lambda elapsed: None)

    def _remaining(self):
        return sum(1 for r in self.registry.all()
                   if r.status == registry.HIDER_STATUS_HIDDEN)

    def on_pick(self, picked_id):
        rec = self.registry.get(self.target_obj, picked_id)
        if rec is None:
            self._on_log("Miss!")
            return
        if rec.status == registry.HIDER_STATUS_FOUND:
            self._on_log("Already found!")
            return
        self.registry.mark_found(self.target_obj, picked_id)
        cmd.color('green', "%s and id %s" % (self.target_obj, picked_id))
        remaining = self._remaining()
        self._on_log("Found one! %d remaining" % remaining)
        self._on_remaining_changed(remaining)
        if remaining == 0:
            self.win()

    def win(self):
        elapsed = time.time() - self._start_time if self._start_time else 0.0
        self._on_win(elapsed)
        if self._wizard is not None:
            self._wizard.deactivate()
            self._wizard = None
    ```

    Note: lowercase `id` in the selection expression (`"obj and id N"`) — that's
    a selector keyword (selecting.py:142). UPPERCASE `ID` is only for iterate
    expressions (AGENTS.md). Do NOT confuse them.
  </implementation>
</feature>
